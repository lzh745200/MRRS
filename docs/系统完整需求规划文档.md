> 版本：v1.10.0 规划基线　|　更新日期：2026-08-24

## 1. 系统概述

### 1.1 建设目标

面向军地联合帮扶乡村振兴场景，提供覆盖"帮扶村 → 帮扶项目 → 经费使用 → 成效评估"全链路的数字化管理能力，满足：

- **离线可用**：无网络环境下完整运行，数据本地 SQLite 存储；
- **多机协同**：通过权限包、配置包、数据上报包在隔离机器间安全流转；
- **安全合规**：机器码绑定 + JWT + 审计留痕 + 数据组织隔离，符合军用软件审计要求；
- **决策支撑**：数据分析、成效评估、KPI 汇总为各级管理者提供量化依据。

### 1.2 技术架构总览

| 层 | 技术 | 说明 |
|----|------|------|
| 桌面壳 | Electron 33 + electron-builder | NSIS (Win x64) / DEB (Kylin ARM64) |
| 前端 | Vue 3 + TypeScript strict + Element Plus + ECharts + Pinia | Vite 构建，~90 视图组件 |
| 后端 | FastAPI + SQLAlchemy 2.0 + Pydantic | ~47 路由模块，~60 服务 |
| 存储 | SQLite（WAL）+ diskcache | 单文件库 `backend/data/rural_revitalization.db` |
| 任务 | threading.Timer 调度器（KPI 预计算/异常检测/提醒/自动备份/回收站保留期） | 见 backup_scheduler.py |

## 2. 功能需求（按模块）

### 2.1 帮扶村管理

- F-V01 村档案 CRUD + 组织归属 + 数据范围过滤
- F-V02 年度板块数据填报（人口/收入/产业/基建/党建/医疗/消费/就业/教育/村委会）
- F-V03 过渡期资金登记与年度对比
- F-V04 Excel 批量导入 / 多格式导出
- F-V05 回收站：软删可见 + 一键恢复 + 彻底删除（级联清除子表 + 密码确认 + 预览统计 + 即时备份）
- F-V06 金额字段统一 4 位小数

### 2.2 项目管理

- F-P01 新建/编辑项目：资金投入(万元)支持 4 位小数
- F-P02 状态机 + 进度跟踪 + 附件
- F-P03 软删回收；统计出口全面排除软删项目
- F-P04 与经费、任务、村庄关联视图

### 2.3 经费管理

- F-F01 七阶段生命周期
- F-F02 预算编制/执行监控/预警（ADR-0009 三级阶梯）
- F-F03 合同、付款、转账凭证、资产核验
- F-F04 支出明细自动联动 Fund.used_amount/remaining_amount
- F-F05 异常检测（定时任务 + AI 双通道）

### 2.4 数据分析与成效评估

- F-A01 分析首页全员可访问
- F-A02 分析仪表板/地图可视化/年度趋势/跨组织对比
- F-A03 成效评估：量化评分模型，软删村/项目/经费一律不参与
- F-A04 帮扶成效排名：软删村不进榜单
- F-A05 KPI 汇总：端点与预计算任务共用 compute_kpi_summary_data() 唯一实现

### 2.5 权限与多机协同

- F-S01 RBAC 角色 + 用户直接权限 + 菜单套餐三层体系
- F-S02 权限配置包：整包/按角色部分导出、Fernet 密码加密、内容校验和强校验、username 映射跨机还原、merge/overwrite 双模式、机器码绑定（可选）、登录前离线导入仅限本机来源
- F-S03 配置包、数据上报包
- F-S04 机器码绑定 + 通行码验证 + 2FA 可选

### 2.6 系统与运维

- F-O01 备份：手动创建、自动计划、上传恢复、加密备份透传解密；普通用户只读可申请下载
- F-O02 审计日志/操作日志双轨 + 字段级变更留痕
- F-O03 提醒中心（排除软删项目催办）
- F-O04 回收站保留期策略：RECYCLE_RETENTION_DAYS 配置，每日定时清除超期软删记录
