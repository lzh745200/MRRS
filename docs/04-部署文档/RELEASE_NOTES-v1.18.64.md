# v1.18.64 发布说明

发布日期：2026-11-27

主题：跨机账号包改为页面级授权树，导入侧按授权矩阵收口。

## 本版重点

- **不再手写授权 JSON**：账号包导出按菜单页选择“不开放 / 只读 / 可操作”，服务端从
  `menus.py` 与 `permission_catalog` 推导页面 key 和后端模块 key。
- **页面可操作自动补模块**：页面选择“可操作”时自动写入映射模块的 `edit`；页面只读只写页面 key；
  工作台、大屏等只读页面不能选择“可操作”。
- **空授权包拒绝导出**：导出至少需要一个页面/功能；历史空授权包导入时不写 `OrgGrant`，
  `org.grant_version` 保持 0，不会把用户锁进“只有工作台”的空矩阵。
- **导入账号不写权限码**：`allowed_permissions` 不再由账号包携带，权限上限由页面授权矩阵控制；
  账号菜单必须是所授权页面的子集，越界整包拒绝。
- **授权目录/可签发状态**：新增两个只读接口，前端据此展示当前用户为何不能签发。
- **导入预览与审计**：预览/成功页展示页面、可操作、只读、模块数量；导出/确认审计记录授权摘要，
  目标机成功页提示修改出厂管理员口令。

## 数据与兼容

- 包格式仍为 `.apkg` 的 `ACCTPKG1`，不新增表、不改变加密/签名算法。
- 旧包可导入：空 `grants` 按“不激活矩阵”处理；非空旧包逐项校验页面/模块 key 与级别。
- 账号包仍默认关闭（`ACCOUNT_PACKAGE_ENABLED=false`）；签发需要配置签名私钥/公钥。

## 安装包

- Windows x64：`MRRS-Setup-1.18.64-x64.exe`（以 GitHub Release 资产为准）
- 麒麟 ARM64：`MRRS-Setup-1.18.64-arm64.deb`、`assistance-management-system_1.18.64_arm64.deb`

升级前请备份 `backend/data` 与上传目录；账号包功能需要显式启用并配置签名密钥后使用。
