# v1.18.65 发布说明

发布日期：2026-11-28

主题：权限闭环收口——矩阵菜单按角色收窄、数据范围统一、界面建号首登改密与登录页清理。

## 本版重点

- **矩阵菜单按角色收窄（T05）**：授权矩阵激活后，菜单先取矩阵可见页，再按角色默认页/组子项/控制台页签
  收窄；普通用户不再看到管理员专属页面或控制台页签。用户级 `allowed_menus` 仍只能进一步收窄。
- **数据范围统一（T06）**：新增唯一判定 `has_unrestricted_data_scope`，仅超级管理员可跨组织看全量；
  `apply_scope_filter`、`get_org_scope`、`get_accessible_org_ids` 三个入口统一调用。
  非超管的 `data_scope="all"` 收敛为本组织及子树或仅本人，不再出现“同一账号不同入口不同结论”。
- **界面建号首登改密（T09）**：管理员在系统内新建账号时强制 `must_change_password`，初始口令不再长期有效；
  存量账号不受影响。
- **登录页清理（T10）**：副标题改为“请输入账号与密码”，删除从未显示的机器码输入框；
  机器码仍由服务端自动绑定，登录功能不变。
- **只读核查工具**：`backend/scripts/check_legacy_account_package_scope.py` 检查旧账号包回执/
  空授权现场；`backend/scripts/audit_data_scope_all.py` 盘点非超管 `data_scope=all` 存量。
  两者均只读，不自动改库。

## 数据与兼容

- 不新增表、不改变账号包格式/加密/签名算法。
- 既有账号的 `data_scope` 字段不改写；仅运行期判定收敛，回退到 v1.18.64 即可恢复旧行为。
- 管理界面新建账号首次登录会被要求改密；如需保持旧行为，需显式修改账号标记（不建议）。
- 账号包仍默认关闭（`ACCOUNT_PACKAGE_ENABLED=false`），签发需配置签名私钥/公钥。

  T09 建号改密回归）。

- `scripts/run_gates.py`：**42/42 PASS**；文档数字门禁、版本同步、更新日志门禁通过。

## 已知边界（不冒充“已上线安全”）

- **T02**：账号包签发/导入需在签发机与目标机配置密钥并完成断网双机演练；代码就绪，现场动作未替做。
- **T04**：写守卫默认仍为 `off`；真实链路回归已补，`shadow`/`enforce` 需试点观察后按单位切换。
- **T07**：未授权模块的读接口仍可被持令牌直接调用；本轮不改默认读策略，需按威胁模型逐模块评估。
- **T08**：旧现场仅在目标机运行只读核查脚本；本机库无回执表，判定“从未导入旧包”。
- **T11–T14**：控制台整页授权、麒麟/升级配置实测、流式导出、版本漂移核对均按方案边界保留，
  不阻塞本版安装包交付。

## 安装包

- Windows x64：`MRRS-Setup-1.18.65-x64.exe`（以 GitHub Release 资产为准）
- 麒麟 ARM64：`MRRS-Setup-1.18.65-arm64.deb`、`assistance-management-system_1.18.65_arm64.deb`

升级前请备份 `backend/data` 与上传目录；账号包功能需要显式启用并配置签名密钥后使用。
