# 帮扶管理信息系统 — 国产电脑一键安装指南

> **版本**: v1.2.0 | **更新**: 2026-05-30 | **适用**: 麒麟V10、UOS、Ubuntu 22.04+

---

## 快速开始（3 步安装）

### 步骤 1: 获取 .deb 安装包

将 `assistance-management-system_1.2.0_arm64.deb` 复制到国产电脑任意目录。

### 步骤 2: 一键安装

```bash
sudo dpkg -i assistance-management-system_1.2.0_arm64.deb
```

如果提示缺少依赖，运行：

```bash
sudo apt-get install -f -y
```

### 步骤 3: 访问系统

打开浏览器访问 `http://localhost:8000`

默认账号: `admin`
默认密码: **出厂口令**（定义于 `backend/app/core/constants.py::FACTORY_ADMIN_PASSWORD`；
未设置 `DEFAULT_ADMIN_PASSWORD` 时种子逻辑即使用该值）。

- 首次登录后系统**强制要求修改密码**（服务端拦截：未改密前除改密/登出/续期外一律 403）；
- 保密部署请勿使用出厂口令：在 `deploy/kylin/config/kylin.env` 中取消注释并填入
  `DEFAULT_ADMIN_PASSWORD=<你的强口令>`，再重启服务（**不会**自动生成随机口令）。

## 多机 / 局域网部署安全必配项（v1.15.7）

> 单机离线（仅本机 `127.0.0.1` 访问）无需本节配置；**多机 / 局域网 / 非回环部署**必须执行。

### 1. PASS_CODE_SECRET：所有实例必须配置同一随机值

- 未配置 `PASS_CODE_SECRET` 时，来自**非本机回环地址**的自助注册/通行码自验证会被
  **fail-closed 拒绝（403）**——表现为"用户在别的机器注册时提示通行码无效"。
- 配置方式（所有实例保持一致）：

  ```bash
  # Linux DEB：编辑 systemd EnvironmentFile 后重启服务
  sudo nano /opt/assistance-management-system/config/kylin.env
  # 追加（示例，请替换为 ≥32 位随机值；所有实例同值）：
  # PASS_CODE_SECRET=<同一随机密钥>
  sudo systemctl restart assistance-management-system
  ```

  Windows 安装版：配置系统/用户环境变量 `PASS_CODE_SECRET`（Electron 启动后端时继承）。
- 密钥不得提交版本库；更换密钥会使已签发的 HMAC 通行码全部失效，需重新签发。

### 2. viewer 角色为严格只读

- `viewer`（访客）只能读取：所有写操作（POST/PUT/PATCH/DELETE，含直连 API）由服务端
  返回 **403**；前端隐藏按钮只是体验层，不是权限边界。
- 需要录入/审批/导出的账号请使用 `user` 及以上角色。

> 完整部署安全口径见 [部署文档总览](../README.md) 的「部署前置检查（安全红线）」。

## .deb 构建方法

### 方法一：Docker 构建（推荐，2026-08-27 起为唯一构建方式）

> 历史脚本 `build-scripts/build-deb-ubuntu.sh` 已不存在；现统一使用
> `docker/Dockerfile.kylin-standalone`（内置行尾规范化，构建产物与检出环境无关）。

在任意支持 Docker 的机器上：

```bash
# 1. 启用 QEMU 模拟（ARM64 构建需要）
docker run --rm --privileged multiarch/qemu-user-static --reset -p yes

# 2. 构建麒麟 V10 standalone DEB
docker buildx build --platform linux/arm64 \
  -f docker/Dockerfile.kylin-standalone \
  --output dist/ .
```

产物在 `dist/` 目录下（`assistance-management-system_<版本>_arm64.deb`）。

### 方法二：CI 构建（tag 触发）

推送 `v*` 标签后，GitHub Actions 自动构建并附加到 Release：

- `kylin-arm64-deb`（Electron 版 DEB）
- `assistance-management-system_*_arm64.deb`（standalone DEB，见 workflow build-arm64.yml）

### 方法三：WSL2 (Windows)

在 Windows 10/11 上启用 WSL2：

```powershell
# 管理员 PowerShell
wsl --install -d Ubuntu-22.04
```

然后在 WSL2 Ubuntu 终端中运行构建脚本。

## 离线安装（无网络环境）

1. 在有网络的机器上准备好 .deb 文件
2. 使用 U 盘复制到目标机器
3. 安装依赖包（预先下载到 U 盘）：

```bash
# 在有网络的机器上
apt-get download libgtk-3-0 libnotify4 libnss3 libxss1 libxtst6 libatspi2.0-0 libuuid1 libgbm1 libasound2 libdrm2
# 将 .deb 文件复制到 U 盘

# 在离线目标机器上
sudo dpkg -i *.deb
```
