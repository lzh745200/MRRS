# 权限包管理与数据上报接收操作说明（v1.8.3 补充）

本文档补充说明「权限包管理」与「数据上报与接收（含自动校验纠正）」两大功能板块的操作流程，随 v1.8.3 版本更新。

---

## 一、权限包管理

### 1.1 功能概述

「权限包」即**菜单套餐**：管理员把一组可见菜单打包成一个权限包，批量绑定给普通用户，控制其可见功能板块。

- **菜单可见性优先级**：用户个人菜单配置 > 绑定的（启用中的）权限包 > 角色默认菜单。
- **改包即全员生效**：修改权限包内的菜单后，所有绑定该包的用户菜单即时同步更新。
- **未绑定用户行为不变**：未绑定权限包的用户继续使用角色默认菜单。
- **绑定范围**：仅可绑定 `user`（普通用户）/ `viewer`（访客）角色；`admin`/`super_admin` 无需套餐控制，绑定会被拒绝。
- **入口**：系统管理 → 权限包管理（仅 admin/super_admin 可见）。

### 1.2 入口

侧边栏 → 系统管理 → 权限包管理

### 1.3 界面说明

权限包列表展示以下列：

| 列 | 说明 |
|----|------|
| 名称 | 权限包名称（唯一） |
| 描述 | 可选说明文字，无则显示 `-` |
| 菜单数 | 该包勾选的可见菜单数量 |
| 绑定人数 | 当前绑定到该包的用户数量 |
| 状态 | 启用 / 停用 |
| 创建时间 | 权限包创建时间 |
| 操作 | 编辑 / 绑定用户 / 删除 |

### 1.4 操作步骤

#### 1.4.1 新建权限包

1. 点击「新建权限包」按钮。
2. 填写「名称」（必填，且全局唯一）。
3. 填写「描述」（可选）。
4. 通过「状态」开关设置启用 / 停用（默认启用）。
5. 在「可见菜单」树中勾选要开放的菜单（父子联动，勾选父级自动包含子级）。
6. 点击「保存」。保存时系统校验所有菜单 key 是否合法，非法项会提示并拒绝保存。

#### 1.4.2 编辑权限包

1. 在列表点击「编辑」。
2. 修改名称、描述、状态或可见菜单。
3. 点击「保存」。**菜单变更对已绑定用户即时生效**。

#### 1.4.3 绑定用户

1. 在列表点击「绑定用户」。
2. 对话框内列出所有 `user` / `viewer` 角色账号（含用户名、姓名、角色、「当前权限包」列，显示「本包 / 其他包 / 角色默认」）。
3. 勾选要绑定的用户（已绑定本包的用户会自动预勾选）。
4. 点击「保存」。系统自动对比勾选变化，分别执行绑定 / 解绑：新勾选的用户绑定到本包，取消勾选的用户解绑（回落到角色默认菜单）。

#### 1.4.4 删除权限包

1. 在列表点击「删除」并确认。
2. **注意**：若该包仍有绑定用户，系统会拒绝删除，提示「该权限包仍绑定 N 个用户，请先解绑后再删除」，需先在「绑定用户」中全部取消勾选后再删除。

#### 1.4.5 查看用户的权限包

用户管理列表新增「权限包」列，展示每个用户当前绑定的权限包名称（未绑定则不显示 / 显示角色默认状态）。

### 1.5 注意事项

- 权限包名称全局唯一，重名会被拒绝。
- 绑定对象仅限 `user` / `viewer`；尝试绑定 `admin` / `super_admin` 会整体拒绝并列出非法用户。
- 目标用户必须真实存在，不存在的用户 id 会导致本次绑定整体拒绝。
- 解绑后用户自动回落到角色默认菜单，不会残留历史权限。
- 权限包全部操作仅管理员（admin / super_admin）可用，其他角色访问返回 403。

## 二、数据上报与接收（含自动校验纠正）

### 2.1 功能概述

整体流程：

```
下级录入数据 → 生成数据包 → 一键上报（zip + 清单 + sha256）
  → 管理员接收上传 → 自动字段级校验纠正
  → 预览报告（ok / corrected / rejected 三级）→ 确认入库（rejected 行跳过并注明原因）
```

- **数据包格式**：ZIP 压缩包，内含数据清单（manifest.json，记录组织编码、数据类型、各类型记录数、版本、sha256 校验和）与各数据类型数据文件。
- **上报范围**：非管理员导出**仅含本人录入的数据**；管理员导出为**全组织**数据。
- **接收与入库**：仅管理员可接收 / 导入 / 确认入库；普通用户访问接收页面会看到「仅管理员可接收数据包」提示。

### 2.2 数据上报（下级上报）

#### 2.2.1 入口

侧边栏 → 数据上报 → 数据上报

#### 2.2.2 操作步骤

1. **选择范围**：选择「上报年度」、勾选要上报的「数据类型」（帮扶村 / 项目 / 经费 / 学校 / 乡村工作，默认全选）、可选填写「备注说明」。
2. **预览数据**：点击「下一步：预览数据」，系统统计各数据类型的记录数（记录数为 0 的类型会给出警告提示）。
3. **生成导出**：点击「生成数据包」，系统打包并自动下载 ZIP（如未自动下载可手动点击「下载数据包 (ZIP)」）。

#### 2.2.3 一键上报

页面右上角「一键上报」按钮：使用当前选择的范围，自动完成「生成数据包 → 下载」两步，适合快速上报场景。

#### 2.2.4 上报范围提示

- 非管理员登录时，页面顶部会显示「仅导出您本人录入的数据」提示（后端按 `export_scope=self` 强制过滤）。
- 管理员登录时不显示该提示，导出范围为全组织数据。

### 2.3 接收数据包（管理员）

#### 2.3.1 入口

侧边栏 → 数据上报 → 接收数据包（仅 admin / super_admin 可见）

#### 2.3.2 页签

| 页签 | 说明 |
|------|------|
| 上报列表 | 待接收 / 已接收 / 已拒绝的数据包列表 |
| 接收记录 | 仅管理员可见，逐条查看接收状态与校验结果 |

#### 2.3.3 筛选

上报列表支持按「上报单位」「状态（待接收 / 已接收 / 已拒绝）」「上报时间范围」筛选。

#### 2.3.4 从本地文件导入

适用于通过 U 盘等介质拷贝过来的上报数据包：

1. 点击「从本地文件导入」。
2. 拖放或选择数据包 ZIP 文件。
3. 系统自动校验文件结构（清单 + 各数据文件），并生成本次导入的字段级校验报告。
4. 确认数据包信息后点击「确认导入」。

#### 2.3.5 列表操作

| 操作 | 说明 |
|------|------|
| 预览 | 打开数据预览，按数据类型分页展示样例数据 |
| 接收 | 确认接收该数据包（仅 pending / submitted 状态可用） |
| 拒绝 | 拒绝数据包，**必须填写拒绝原因** |
| 下载 | 下载原始数据包 ZIP |

### 2.4 自动字段级校验与纠正

接收 / 导入数据包时，系统对「帮扶村 / 项目 / 经费 / 学校」四类数据逐行做字段级校验，并自动纠正可修复的格式问题。

#### 2.4.1 校验规则

| 类别 | 规则 |
|------|------|
| 必填字段 | 非空且无默认值的列，缺失即判为不通过（「缺少必填字段: xxx」） |
| 枚举字段 | 状态 / 类型等字段取值必须在允许值内，否则「取值非法（可选: …）」 |
| 手机号 / 电话 | 去除分隔符后校验 11 位手机号（1 开头）或带区号座机；否则「电话格式不正确」 |
| 日期字段 | 支持 YYYYMMDD / YYYY-M-D / YYYY/M/D / ISO 格式；无法识别则「日期格式无法识别」 |
| 数值字段 | 数字字符串转数值；金额 / 预算 / 数量等字段拦截负数；整数列不可为小数 |

#### 2.4.2 自动纠正

| 纠正 | 说明 |
|------|------|
| 去首尾空格 | 字符串字段去除首尾空格（trim） |
| 空字符串转空值 | 可空列的空字符串自动转为空值（NULL） |
| 手机号去分隔符 | 手机号 / 电话中的 `-`、空格自动去除 |
| 日期归一 | 各种日期写法统一归一为 ISO 格式（如 `20260101` → `2026-01-01`） |
| 数字字符串转数值 | `"123"` → `123`、`"3.5"` → `3.5`（含去除千分位逗号） |

### 2.5 预览报告与确认入库

系统对每条记录给出三级结论：

| 结论 | 含义 | 入库处理 |
|------|------|----------|
| ok | 无需纠正，直接通过 | ✅ 直接入库 |
| corrected | 存在格式问题，已自动纠正 | ✅ 以纠正后的数据入库，并记录纠正明细 |
| rejected | 无法纠正（如缺必填、枚举非法、日期无法识别） | ❌ 跳过该行，并注明具体原因 |

- 预览对话框中会展示「字段校验报告」：各数据类型「通过 N 条 / 纠正 N 条 / 拒绝 N 条」计数摘要 + 前 5 条问题明细（拒绝原因 / 纠正内容）。
- 确认入库时，`ok` 与 `corrected`（纠正后数据）执行写入；`rejected` 行被跳过，并在校验结果中注明「第 N 行校验未通过: …」的原因。

### 2.6 接收记录视图（仅管理员）

「接收记录」页签逐条展示已接收数据包，包含：包编号、来源组织、上报人、文件名、大小、记录数、**校验结果（通过 / 纠正 / 拒绝计数）**、状态、接收时间；已校验包可再次「预览」（同时查看字段校验报告）或「下载」。

### 2.7 注意事项

- 接收 / 导入 / 确认入库操作仅管理员可用（后端对非管理员强制 403）。
- 拒绝数据包必须填写拒绝原因，否则无法提交。
- 数据包为 ZIP 文件，请勿手动修改包内清单或数据文件，否则会导致结构校验失败或 sha256 校验不通过。
- 字段级自动校验仅覆盖「帮扶村 / 项目 / 经费 / 学校」四类；其他类型按原样放行（仅做结构校验）。
- 被纠正（corrected）的行以纠正后的值入库，建议在预览报告中核对纠正明细后再确认入库。
