# 经费管理操作流程详解（v1.10.0）

> 适用版本：v1.10.0 单机版。经费全生命周期共 8 个阶段，页面顶部步骤条实时标示当前所处阶段。

## 一、阶段总览（顶部步骤条）

```
预算编制 → 经费申请 → 审批 → 拨付 → 使用执行 → 报销核销 → 决算结算 → 归档
```

- 入口：侧边栏「经费管理 → 经费总览」，页首横向步骤条可点击跳转对应功能页。
- 状态九态对照：待审批(pending) / 已计划(planned) / 已审批(approved) / 已拨付(allocated) /
  使用中(in_use) / 已完成(completed) / 已审计(audited) / 已驳回(rejected) / 已取消(cancelled)。

## 二、各阶段操作要点

### 1. 预算编制
入口：经费管理 → 预算管理。按科目建立预算（科目+金额），支持分类执行进度仪表盘。
预算执行到 **80% 提醒 / 95% 预警**（后端阈值），超支前请先调整预算。

### 2. 经费申请
入口：经费申请（普通用户）。填写名称/类型/来源/金额/用途后提交，状态进入"待审批"。
**编号规则**：手工编号选填；留空时系统自动生成 `ZJ + 年份 + 流水号`。

### 3. 审批
- 审批人路径：待审批板块或经费详情「审批」按钮。
- **驳回必须填写原因**（前后端双重校验），原因会写入状态历史与关联审批任务。
- 通过后状态变为"已审批"。

### 4. 拨付
前置条件：已上传 **合同** 与 **拨款凭证** 两类附件（缺失时拨付被拦截）。
填写实拨金额与拨付方式，确认后生成拨付记录，状态→"已拨付"。

### 5. 使用执行
状态推进：开始使用 → 使用中；完成后点"完成使用"。全程在详情页「附件管理」留存票据。

### 6. 报销核销
合同付款登记、转账凭证确认均在对应页签操作；每笔核销自动累计已用金额并扣减剩余可用。

### 7. 决算结算
项目结束后：资金周期页（七阶段生命周期）或决算结算页生成决算报告（编号 JS-YYYYMMDD-NNNN），
支持决算审批与绩效评分。

### 8. 归档
已审计经费自动进入历史台账；详情页四个日志页签（审批流程/状态日志/修改记录/操作日志）
+ 附件管理构成完整档案链，满足军规留痕要求。

## 三、常见问题

| 现象 | 处理 |
|---|---|
| 拨付按钮灰色 | 缺合同或拨款凭证附件，先在附件页签上传 |
| 驳回时提示"必须填写原因" | 填写不少于 1 字的驳回原因 |
| 列表出现英文状态 | v1.10.0 已修复；若复现请联系管理员刷新缓存 |
| 工作台快捷按钮跳错 | v1.10.0 已修复为直达资金周期/决算结算页 |
