# 审批管理、数据分析与备份管理操作说明（v1.8.0 补充）

本文档补充说明审批管理、数据分析、备份管理三个板块的操作流程，随 v1.8.0 版本更新。

---

## 一、审批管理操作流程

### 1.1 流程总览

```
待审批 → 审批中 → 已通过 / 已驳回
```

- **待审批**：申请提交后进入待审批列表，由审批人处理
- **审批中**：多级审批流中当前审批人正在处理
- **已通过**：审批通过，业务数据生效（如经费进入"已审批"状态）
- **已驳回**：审批驳回，需填写驳回原因，申请人可修改后重新提交

### 1.2 入口

侧边栏 → 审批管理 → 待审批 / 我的申请 / 审批历史

### 1.3 操作步骤

1. **查看待审批任务**：审批管理 → 待审批，列表展示优先级、类型、提交时间与超时标记
2. **查看详情/变更对比**：点击审批标题查看申请信息与字段级变更对比（原值 → 新值）
3. **通过**：点击"快速通过"或进入详情后确认通过；批量通过支持勾选多条
4. **驳回**：点击"拒绝"→ **必须填写驳回原因**（textarea 必填）→ 确认
5. **转交（v1.8.0 新增）**：点击"转交"→ 选择目标审批人（下拉可搜索，自动排除当前审批人）→ 填写可选转交原因 → 确认
6. **一键全部通过**：适用于单机版内部审核场景的批量放行

### 1.4 筛选

- 待审批列表支持按**类型**（帮扶村/项目/经费/学校/乡村工作）与**提交时间范围**筛选，列表展示提交人
- 审批中心支持「待我审批 / 我发起的 / 已完成」状态页签切换与批量通过/驳回（驳回原因必填）
- 审批历史支持按**类型**（实体类型）与**状态**（待审批/已通过/已驳回）筛选
- 我的申请支持按**状态**与**时间范围**（daterange）筛选

## 二、数据分析使用指南

### 2.1 入口

侧边栏 → 数据分析（或 帮扶数据管理 → 数据统计分析）

### 2.2 功能模块

| 页签 | 内容 |
|------|------|
| 经费投入 | KPI 统计卡（帮扶村总数/总投入/数据完整率/进行中项目）+ 投入趋势折线图 + 分类统计 + 地区分布 |
| 年度对比（v1.8.0 增强） | 选择两个对比年份，展示帮扶村总数/总投入/人均收入对比；含**投入 vs 收入柱线组合图**（全部有数据的年份）；无数据时显示空态提示 |

### 2.3 年度对比操作步骤

1. 切换到"年度对比"页签
2. 选择对比年份 A（默认去年）与年份 B（默认今年）
3. 系统展示两个年份的帮扶村总数、总投入（万元）、人均收入（万元）对比值
4. 下方柱状图展示历年总投入与人均收入趋势（点击年份下拉实时联动）

> 提示：年度对比数据来源于帮扶村年度数据管理中各板块录入的数据；如显示"暂无年度数据"，请先在帮扶村详情 → 年度数据管理中录入。

## 二之二、帮扶成效板块使用指南（v1.8.2 修订）

### 入口

侧边栏 → 帮扶成效 → 成效排名 / 成效评估

### 成效排名

1. 选择「评估年度」与「显示数量」，点击"查询"
2. 表格展示：排名、村庄名称（点击进评估页）、帮扶单位、总分（含进度条）、等级、经济/社会/生态三唯得分
3. 操作列：管理员显示「评估」，其他角色显示「查看」（均跳转成效评估页）

### 成效评估

1. 选择村庄与评估年度
2. 页面自动加载该村该年度**已有评估报告**（只读）；若未评估，提示"该年度尚未评估"
3. 管理员可点击「开始评估」重新计算并覆盖当年评估结果；评估依据该村年度收入/基础设施/产业数据自动计算三唯分数
4. 报告含：总分、等级、排名、经济/社会/生态得分、评估时间及指标明细（人均收入、收入增长率、基础设施/产业项目数、数据完整度）
5. 年度对比：选择两个不同年度点「对比」，展示两年总分与总分/三唯得分变化量（如缺少某年数据会明确提示）
6. 评估完成后系统自动生成"年度考核复核"审批任务（同村同年度不重复生成），在 审批管理 → 待审批 中处理

> 角色说明：viewer 仅可查看排名与报告；user 可查看；评估操作仅 super_admin/admin。

## 三、备份管理操作说明

### 3.1 唯一入口（v1.8.0 起）

**系统管理 → 备份管理**（原"数据管理 → 数据备份"入口已删除/重定向，备份功能唯一收口于此）。

### 3.2 功能

| 功能 | 说明 |
|------|------|
| 创建备份 | 手动创建完整数据备份（可设置加密密码） |
| 自动备份 | 定时自动备份（可配置间隔与保留份数） |
| 恢复备份 | 从备份包恢复数据（支持加密包：输入密码后解密恢复） |
| 导入备份包 | 上传任意机器导出的备份包（含加密包，8MB 分块流式传输） |
| 导出备份 | 下载备份包用于迁移/存档 |

### 3.3 操作步骤（恢复）

1. 系统管理 → 备份管理 → 选择备份记录
2. 点击"恢复"（加密备份需输入创建时设置的密码）
3. 确认后系统恢复数据库并自动跳转登录页
4. 恢复前建议先创建一份当前数据备份

### 3.4 备份结果通知（v1.8.0 新增）

- 自动备份无论成功或失败，都会向全部管理员（admin/super_admin）推送「备份提醒」类型消息（消息中心可筛选查看）
- 消息中心仅保留最近 **30 天**的消息，每日凌晨自动清理更早记录（归档）
