# 用户手册

本目录包含系统的用户使用手册和操作指南。

> 导航口径：v1.17.1 起左侧导航为 **7 个板块**（工作台 + 帮扶业务 / 乡村振兴 / 工作协同 / 分析汇报 / 数据管理 / 系统管理），
> 系统管理收敛为 **6 个聚合页**（组织与权限 / 安全与审计 / 运维与监控 / 备份与存储 / 系统设置 / 关于与反馈，页内 Tab 切换）。
> 各手册中的「侧边栏 → …」路径已按新导航更新；完整导航说明见 [使用指南](./使用指南.md) 的「导航与菜单」章节。
> **v1.15.15**：新增「界面精细化」说明（表格/筛选栏/页头统一）；「一户一档」入口并入帮扶村年度数据页，
> 不再出现在侧边栏（详见使用指南 §1 年度数据管理与 §11）。
> **v1.15.18**：系统管理聚合页改为「左侧分组导航 + 右侧内容」，Ctrl+K 菜单搜索可直接跳到 30 个系统管理子功能；
> 详见 [系统管理操作说明](./系统管理操作说明.md)。

## 🎯 使用建议

### 新用户

1. 先阅读 [使用指南](./使用指南.md) 的「快速开始」与「导航与菜单」章节
2. 再按业务模块查阅对应的操作说明

### 经验用户

- 直接查看具体模块的操作说明
- 参考 [使用指南](./使用指南.md) 中的高级功能
