# 审批管理操作流程（含转审）v1.10.0

## 一、角色与入口

| 角色 | 入口 | 能力 |
|---|---|---|
| 审批人 | 审批管理 → 待审批 | 快速通过 / 转交 / 拒绝 / 变更对比 / 批量通过 |
| 申请人 | 我的申请 | 撤回 / 重新提交 / 进度跟踪 |
| 管理员 | 审批概览 | 一键全部通过（单机版）、全量统计 |

## 二、标准审批流

1. **待审批列表**：支持按类型（经费/项目/村/学校/乡村工作/考核复核）与提交时间筛选。
2. **详情与对比**：点「对比」查看字段级变更 diff（改前 vs 改后）；点「详情」跳转业务实体页。
3. **快速通过**：单机模式下优先走标准审批；无工作流配置时自动回退单机直批。
4. **拒绝**：必须填写拒绝原因（非空校验），原因回传申请人消息中心。
5. **批量通过**：勾选多条 → 批量通过，可附统一意见。

## 三、转审（转交）

适用：当前审批人不是合适处理人。

1. 待审批列表行内点「转交」。
2. 弹窗中选择目标审批人（支持按姓名关键词过滤，排除自己）。
3. 确认后任务从你的列表消失，出现在对方待审列表；双方均收到站内消息。

> 说明：转交不改变任务实体内容，仅变更 current_approver；审批链历史完整保留。

## 四、撤回与重新提交（申请人）

- 我的申请 → 状态"待审批"的任务可「撤回」；被拒绝的任务修改后可「重新提交」。
- 撤回/重提同样写入审批历史时间线。

## 五、通知联动

- 提交/通过/驳回/新任务四类事件均写入消息中心（类型=审批通知），
  点击消息可直接跳转对应实体详情或待审列表。
- 顶栏铃铛角标 = 未读消息数（60 秒轮询）；Electron 托盘图标同步显示数字角标。

## 六、年度考核复核去重

同一村同一评估年度重复发起评估时，系统复用既有"年度考核复核"任务，不再产生重复待办。
