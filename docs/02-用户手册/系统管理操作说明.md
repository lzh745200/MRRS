# 系统管理操作说明（v1.15.18）

> 适用版本：v1.15.17 起（左侧分组导航 + Ctrl+K 直达子功能）
> 入口：侧栏「系统管理」→ 6 个聚合页；页内左侧导航按业务分组，右侧为具体功能页。

## 一、结构总览（6 聚合页 / 30 个功能）

| 聚合页 | 分组 | 功能（Tab） |
|---|---|---|
| **组织与权限** | 账号与组织 | 用户与组织 |
| | 权限配置 | 角色管理、菜单管理、权限包管理 |
| | 组织与单位 | 组织机构、单位授权配置、导入授权包 |
| **安全与审计** | 审计 | 安全审计 |
| | 访问控制 | 零信任、机器码管理 |
| | 密钥与加密 | 密钥管理、数据分级、加密设置 |
| **运维与监控** | 运行状态 | 系统总览、健康检查、系统监控、缓存管理、运行环境 |
| | 任务与日志 | 后台任务、错误上报 |
| **备份与存储** | 备份 | 数据备份 |
| | 数据包与存储 | 分片上传、地图瓦片、管控配置包、系统配置包 |
| **系统设置** | 系统设置 | 更新日志 |
| **关于与反馈** | 关于与反馈 | 关于系统、意见反馈、帮助中心、管理员看板 |

### 三种进入方式
1. **侧栏 → 聚合页 → 左侧分组 → 功能**：常规路径。
2. **Ctrl+K 菜单搜索**：直接输入功能名（如"权限包""备份""机器码"）回车跳转，自动落到对应 Tab。
3. **深链**：`/system/console/<group>?tab=<key>`，可直接复制分享/加书签；刷新保持当前 Tab。

> 所有旧地址（如 `/system/users`、`/system/backup`）**仍然可用**，不产生 404；
> `/system/roles`、`/system/user-permissions` 会重定向到新页面。

## 二、组织与权限

### 1. 用户与组织（`users-orgs`）
- **新增用户**：右上「新增用户」→ 用户名 / 姓名 / 角色 / 组织 → 保存。
- **编辑**：行内「编辑」改角色、组织、状态；**重置密码**需二次确认。
- **审核待注册用户**：页面顶部横幅 → 通过 / 驳回。
- **数据范围**：super_admin=全部；部门级 admin=本组织及子树；user=仅本人；viewer=只读（服务端 403 拦截写操作）。
- 首次登录或被重置密码的用户，受 `must_change_password` 强制改密。

### 2. 角色管理（`roles`）
- 查看 4 个系统角色（super_admin / admin / user / viewer）的默认菜单。
- 历史角色值（approval_leader / manager → admin，operator → user）由 `normalize_role` 自动归一化，无需手工迁移。

### 3. 菜单管理（`menus`）
- **只读视图**：菜单唯一源在后端 `menus.py`，此处用于核对结构与权限归属，不作为编辑入口。

### 4. 权限包管理（`system-permission-packs`）
- 新建权限包 → 勾选菜单 key → 绑定用户或角色 → 启用/停用；支持导出/导入。
- 授权优先级：**用户 `allowed_menus` > 启用中的权限包 > 角色默认**。
- 建议：给普通用户授权优先用权限包，不要逐用户改 `allowed_menus`。

### 5. 组织机构（`organizations`）
- 左侧组织树 + 右侧详情；新建/编辑需填名称、编码、上级组织，系统自动维护 `path`/`level`（数据权限的根）。
- 删除受限：名下存在项目或用户时禁止删除（提示先转交）。
- 变更上级组织会影响整棵子树的数据权限范围，操作前确认。

### 6. 单位授权配置（`system-org-grant`，R33，上级单位）
- 选择下级单位 → 勾选模块的写权限（view / edit）→ 生成授权包（Ed25519 签名）→ 下发。
- 前置：下级机需配置 `GRANT_PUBKEY`；`GRANT_ALLOW_UNSIGNED` 必须为 false。

### 7. 导入授权包（`system-grant-import`，R33，下级单位）
- 选择授权包文件 → 校验签名/版本（**禁止降级**）→ 导入后本机按上级矩阵只读执行。
- 注意：单位编码必须一致；授权包版本严格单调。

## 三、安全与审计

### 1. 安全审计（`audit`）
- 按用户 / 操作 / 资源 / 时间筛选审计日志，可导出；高风险操作红色标记。

### 2. 零信任（`zero-trust`）
- 设备登记与指纹；策略开关默认宽松，生产建议先开 shadow 观察再收紧。

### 3. 机器码管理（`machine-code`）
- 查询机器码；生成通行码（单条/批量）→ 用户在本机注册时使用。
- 通行码一次性有效；多机部署需统一 `PASS_CODE_SECRET`。
- 机器码 + 通行码校验失败时会按"仅通行码（pending 记录）"三级回退，避免 Windows 机器码漂移导致注册失败。

### 4. 密钥管理（`secrets`）
- 查看/轮换加密密钥；**变更后需重启后端生效**；多机部署必须使用相同 `ENCRYPTION_KEY`。

### 5. 数据分级（`data-tier`）
- 查看 PII 字段的加密状态与分级规则；PII 列为透明加密（AES-SIV，密文带 `enc.v1:` 前缀）。

### 6. 加密设置（`encryption`）
- 调整加密策略；变更后需重启后端。

## 四、运维与监控

### 1. 系统总览（`system-overview`）
- 系统健康状态、快捷入口、最近审计日志、版本/构建信息。
- 快捷入口仅保留有效页面（历史死链已清理，且有门禁防复发）。

### 2. 健康检查（`health-check`）
- 数据库 / 磁盘 / 内存 / 任务队列健康卡片；维护窗口期间 `/health` 会返回 `maintenance` 字段。

### 3. 系统监控（`monitor`）
- 实时指标曲线（请求量、耗时、错误率）。

### 4. 缓存管理（`cache`）
- 查看命中率、按命名空间清理；清缓存不影响数据。

### 5. 运行环境（`environment`）
- 依赖/路径/版本自检，可一键体检。

### 6. 后台任务（`tasks`）
- 查看备份/导出/同步任务状态，支持重试。

### 7. 错误上报（`error-reports`）
- 错误列表与详情（堆栈、发生时间、影响用户）。

## 五、备份与存储

### 1. 数据备份（`backup`）
- **创建**：填备注 → 生成备份（含校验）→ 出现在列表；普通用户可创建，下载/恢复/删除限管理员。
- **恢复**：选择备份 → 确认 → 自动开启维护窗口（期间写请求 503、读放行）→ 恢复前校验 SHA256。
- 生产恢复前建议先手工做一次即时备份。

### 2. 分片上传（`chunked-upload`）
- 大文件断点续传；失败可续传，不重复上传已完成分片。

### 3. 地图瓦片（`map-tiles`）
- 离线瓦片包导入/清理；瓦片目录见部署文档。

### 4. 管控配置包（`control-package`）
- 生成/导入管控配置包（含组织与权限矩阵）。

### 5. 系统配置包（`config-package`）
- 导出/导入系统配置（不含业务数据）。

## 六、系统设置 / 关于与反馈

- **更新日志**（`update-logs`）：按版本查看更新内容。
- **关于系统**（`about`）：版本、构建信息、版权与免责声明。
- **意见反馈**（`feedback`）：提交问题反馈。
- **帮助中心**（`help`）：使用说明与常见问题。
- **管理员看板**（`admin-dashboard`）：用户量、数据量、活跃度概览。

## 七、本次增强的操作变化（v1.15.18）

### 1. 危险操作必须二次确认（全部留审计）
| 操作 | 位置 | 确认方式 |
|---|---|---|
| 删除组织 | 组织与单位 → 组织机构 | 输入**当前登录密码**（走 `X-Confirm-Password` 请求头，不落访问日志） |
| 恢复备份 | 备份 → 数据备份 | 弹窗红色警告 + 备份信息 + 加密备份需密码 |
| 轮换密钥 | 密钥与加密 → 密钥管理 | 「这将使所有现有令牌失效」确认 |
| 管理员重置他人密码 | 账号与组织 → 用户与组织 | **手工输入目标用户名**才能确认（新增，防手滑接管账号） |

以上四类操作在执行成功后会写入审计日志（`audit_logs`）：
`organization_delete` / `system_restore` / `secrets_rotate` / `admin_reset_password`，
可在「安全与审计 → 安全审计」按操作类型检索。

### 2. 权限抽屉新增「生效概览」
打开 用户与组织 → 行内「权限」后，抽屉顶部一屏显示：
用户（含姓名）、系统角色（中文 + 原值）、数据范围（中文 + 原值）、
菜单权限来源（自定义 / 沿用角色默认 + 生效项数）、RBAC 可选角色数。
避免在「角色分配 / 权限配置 / 菜单可见性」三个页签之间来回确认。

### 3. 设备与授权中心（机器码页增强）
安全与审计 → 访问控制 → 机器码管理：
- 表格支持**多选**，可「复制所选机器码」「复制所选通行码」（按行换行拼接，方便批量粘贴）；
- 顶部提供「单位授权配置」「导入授权包」直达入口，不再需要回系统管理逐层查找。
- 原「组织通行码」页签完整保留。

### 4. 全局搜索直达（Ctrl+K）
Ctrl+K 现在能搜到系统管理下**全部 30 个功能**（不只是 6 个聚合页），
选中后直接落到对应 Tab；收藏 / 最近访问同样记住具体 Tab。

## 八、权限与兼容说明

- 菜单 key 全量保留：历史权限包 / `allowed_menus` 中的 key 仍然有效。
- 18 个历史兼容 key（如 `email`、`checkin`、`sentiment`、`households`）**无导航出口**，仅用于旧权限包校验，不会产生 404。
- 聚合页可见性 = console key 或任一 tab key 在可访问集合内；勾选聚合页 key 视为其全部 Tab 可见。
- 门禁：
  - `scripts/check_menu_alignment.py`：后端菜单 path ↔ 前端路由（A~E 规则）。
  - `scripts/check_console_tab_mapping.py`：后端 console tab key ↔ 前端 `TAB_COMPONENTS`（防"有菜单无组件"静默消失）。
  - `src/utils/navLinks.ts` + `nav-links.test.ts`：快捷导航 path 必须能在路由表解析（防死链）。
