# 数据分析功能使用指南 v1.15.15

> 导航口径：分析相关页面收在 **分析汇报** 板块（汇报大屏 / 数据分析分组：分析仪表盘、地图可视化、工作分析、成效排名、成效评估 / 报表模板 / 报表导出 / **影像库**）。
> v1.14.0 起原「舆情监测」页面已下线（该菜单 key 仅保留权限兼容），由 **帮扶业务 → 消费帮扶** 台账替代；影像库用于照片归档与多期对比。

## 一、分析仪表板（/data-analysis）

### KPI 卡片区
- 四卡：帮扶村总数 / 覆盖人口 / 平均人均收入 / 帮扶投入。
- 每卡下方为**真实环比**：较上月（村/投入）或较去年（人口/收入，年度数据）。
  - ↑ 绿色 = 增长；↓ 红色 = 下降；→ "持平" = 无变化。
- 卡片右侧 sparkline 为**近 5 年年度走势微缩图**（非模拟数据）。

### 图表区
| 图表 | 解读 |
|---|---|
| 地域分布 | 各市州帮扶村数量占比，点击扇区可钻取该村列表 |
| 投入构成 | 产业/基建/教育三类投入金额对比 |
| 年度趋势 | 村数/覆盖人口(百人)/人均收入三条折线，随年份筛选联动 |

### 筛选联动
顶部年份、部门、地域属性（三区三州/重点帮扶县）任一变化都会刷新全部图表与钻取面板。

## 二、年度关键指标对比

- 默认加载近 5 年；切换年份多选对比柱状/折线。
- 空数据年份显示空态占位而非全 0 图。

## 三、帮扶成效排名与评估

- 排名页：三列榜单（含帮扶单位），支持按年度筛选。
- 评估页：管理员发起评估生成报告（总分/等级/三维度得分）；重复评估自动复用既有审批任务。

## 四、导出

- 报表导出支持 JSON/Excel；导出任务可在历史表中下载（异步任务带 processing 态）。
- 大屏（汇报大屏）入口：**分析汇报 → 汇报大屏**（`/bigscreen`），适合汇报投屏；旧「数据分析页页头 → 更多 → 成效大屏」入口仍可用。
- **退出大屏**：大屏顶部「退出大屏」按钮会先退出全屏、再返回工作台。
- **距离字号档（v1.15.0）**：大屏顶部可选「3m / 6m / 10m」观看距离，默认 6m；远距离大屏选 10m，字形整体放大。
- **自动轮播（v1.15.0）**：默认关闭；开启后每 15 秒在「指标视角 ↔ 图表视角」间切换，可「暂停/继续」或「关闭轮播」。

## 五、汇报大屏按对象筛选

> 入口：**分析汇报 → 汇报大屏**（`/bigscreen`），或从数据分析页页头「更多」→「成效大屏」进入。
> 适合场景：汇报现场领导临时追问"某个村 / 某个学校 / 某个单位帮扶得怎么样"。

### 操作步骤

1. 进入大屏后，顶部筛选条默认为「全部」，显示全局帮扶成效（与旧版一致）。
2. 点击「帮扶村 / 帮扶学校 / 帮扶单位」切换查看类型：系统会自动选中该类的第一个对象并立即加载，随后可在下拉框改选。
3. 在右侧下拉框中输入关键字搜索（村名 / 校名 / 单位名），选中对象后大屏自动刷新为该对象的数据。单位下拉项还会显示"村N·校M·项目K"的覆盖情况，便于判断选哪个单位。
4. 想回到总体情况：点「重置」（选中具体对象后才可点）；也可以直接点「全部」。
5. 右上角「设置」可调整：卡片显示与顺序（含「对象档案」「帮扶明细」两张卡片）、自动刷新频率（30 秒 / 60 秒 / 5 分钟 / 关闭）、汇报脱敏。
6. 汇报结束后点顶部「**退出大屏**」：自动退出全屏并回到工作台。

### 能看什么

| 查看类型 | KPI 指标 | 对象档案 | 帮扶明细 |
|---|---|---|---|
| 全部 | 帮扶村 / 帮扶项目 / 帮扶学校 / 完成率 / 经费总额 | 不显示 | 不显示 |
| 帮扶村 | 总人口 / 总户数 / 帮扶项目 / 经费总额 / 走访次数 | 基础信息、人口与收入、帮扶投入、结对与走访，以及区域标记标签 | 项目前 5、经费前 5、结对数/进行中/走访次数 |
| 帮扶学校 | 学生人数 / 教师人数 / 班级数量 / 学校项目数 / 经费总额 | 基础信息、办学规模、助学帮扶、结对与走访 | 项目前 5、经费前 5、结对数/进行中/走访次数 |
| 帮扶单位 | 覆盖帮扶村 / 覆盖帮扶学校 / 帮扶项目 / 经费投入 / 结对走访次数 | 单位概况 + 覆盖的帮扶村/学校标签 | 项目前 5、经费前 5、结对数/进行中/走访次数 |

无论选中哪类对象，下方的经费执行趋势、经费投入排名、项目状态分布、年度对比、重点项目负责人都会同步切换到该对象的口径：

- **经费执行趋势**：逐年"计划投入 / 实际投入"（万元）。
- **经费投入排名**：全部维度是各村已拨付经费排名；帮扶村 / 帮扶学校维度是该村（校）项目实际投入排名；帮扶单位维度是覆盖村经费排名（无覆盖村时改为项目实际投入排名）。最多 8 条。
- **项目状态分布**：全部/村/单位按项目状态（已完成 / 已审批 / 进行中 / 待审批）；帮扶学校按学校项目阶段（调研 / 立项审批 / 实施 / 验收 / 已完成）。
- **年度对比**：逐年项目数（柱状）。
- **重点项目负责人**：按实际投入排序的前 5 个项目及负责人（脱敏模式下姓名打码；帮扶学校维度因学校项目未单独登记负责人，此处显示项目类别）。

### 口径提示（重要）

- **金额**：单位为万元，保留 2 位小数。
- **完成率**：按"已填报年度数据 ÷ 应填报年度数"计算，显示为百分数（保留 1 位小数）；没有数据显示「—」。
- **人口 / 户数**：每个村取自己**最新上报年份**的数据后再汇总，不是全库最新年份。
- **统计范围**：只统计未删除的数据；项目不含已取消（cancelled）的项目。
- **数据权限**：下拉框只显示当前账号有权查看的对象；直接访问无权或已删除的对象会提示"对象不存在或无权查看"，并自动回到"全部"，不会白屏。
- **单位口径**：单位是登记在村/学校/项目/结对记录上的**文字名称**（村与学校的"帮扶单位"、项目的"负责单位"、结对记录的"帮扶主体名称"），同名会自动合并计数，系统没有单独的"单位档案"表。

### 汇报脱敏模式

- 打开后：金额只显示整数（隐藏小数精度），重点项目负责人姓名打码显示（如"张*三"）。
- 脱敏只影响大屏展示，不修改数据库数据，也不影响导出文件。
- 建议按汇报现场要求决定是否开启；关闭后恢复完整显示。
