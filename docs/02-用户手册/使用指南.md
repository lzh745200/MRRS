# 帮扶管理信息系统 - 使用指南

## 📋 系统简介

**系统名称：** 帮扶管理信息系统（全面推进乡村振兴帮扶工作管理系统）
**版本：** 1.14.0（2026-10-18）
**交付形式：** Electron 桌面应用（离线单机版）
**版权所有：** © 2025 贵州省乡村振兴项目组

本系统是一套完整的乡村振兴帮扶管理平台，以 Electron 桌面应用形式交付，内嵌 FastAPI 后端服务和 SQLite 数据库，无需网络即可运行。用于管理帮扶村、帮扶项目、经费、数据等相关信息。

## 🚀 快速开始

### 1. 系统要求

#### 运行环境（安装包用户）
- **操作系统：** Windows 10/11、银河麒麟 V10（AMD64/ARM64）
- 双击安装包即可使用，无需额外安装 Python 或 Node.js

#### 开发环境
- **Python：** 3.11 或更高版本
- **Node.js：** 18 或更高版本
- **浏览器：** Chrome、Edge、Firefox 等现代浏览器

#### 硬件要求
- **内存：** 至少 4GB RAM（推荐 8GB）
- **磁盘空间：** 至少 2GB 可用空间
- **处理器：** 双核及以上

### 2. 启动系统

#### 方式一：使用启动脚本（推荐）

**Windows用户：**
1. 双击运行 `START_SYSTEM.bat`
2. 选择启动方式：
   - 选项1：仅启动后端服务
   - 选项2：仅启动前端服务
   - 选项3：同时启动前后端（推荐）
3. 等待服务启动完成
4. 系统会自动在浏览器中打开

#### 方式二：手动启动

**启动后端服务：**
```bash
# 进入后端目录
cd backend

# 创建虚拟环境（首次运行）
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动后端服务
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**启动前端服务：**
```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动前端服务
npm run dev
```

### 3. 访问系统

服务启动成功后，可以通过以下地址访问系统：

- **前端地址：** http://localhost:5173
- **后端地址：** http://localhost:8000
- **API文档：** http://localhost:8000/docs

### 4. 停止系统

**Windows用户：**
- 双击运行 `STOP_SYSTEM.bat` 停止所有服务

**手动停止：**
- 在运行服务的命令行窗口中按 `Ctrl + C`

### 菜单搜索、最近访问与收藏

- **菜单搜索（Ctrl+K）**：任意页面按 `Ctrl+K` 打开菜单搜索，输入名称/关键字实时过滤；
  `↑` / `↓` 选择、`Enter` 跳转、`Esc` 关闭。搜索范围覆盖所有页面与系统管理各 Tab。
- **最近访问**：侧栏顶部"最近访问"记录最近打开过的 8 个页面（自动去重、最近的在前）。
- **收藏**：常用页面可加入收藏，显示在侧栏顶部"收藏"区（最多 8 个）。
- **板块折叠**：7 个板块默认折叠，点击板块标题展开/收起；展开状态记忆在本机
  （localStorage `nav:expanded-sections`），下次打开保持上次的展开情况。
- 收藏与最近访问只保存在本机浏览器存储（`nav:favorites` / `nav:recent`），不上传服务器；
  清除浏览器数据会一并清空。

### 为什么我看不到某个菜单？

菜单可见性按三级优先级决定：**用户个人菜单配置 > 绑定的权限包 > 角色默认菜单**
（管理员在「系统管理 → 组织与权限 → 权限包管理 / 用户与组织」配置）。
v1.13.0 起菜单完全由后端统一下发：勾选聚合页（如"组织与权限"）即包含其全部 Tab，
历史只勾过某个 Tab 的配置仍然兼容（v1.14.0 下线页面的旧 key 也仅作权限兼容、不再有导航入口）。
若确认应有权限却看不到，请先用 `Ctrl+K` 搜索定位，或联系管理员检查权限配置。

### 1. 帮扶村管理

#### 访问路径
侧边栏 > 帮扶业务 > 帮扶村管理

#### 主要功能

- **新增帮扶村：** 点击"新增帮扶村"按钮添加新记录
- **编辑帮扶村：** 点击"编辑"按钮修改帮扶村信息
- **查看详情：** 点击"查看"按钮查看帮扶村详细信息
- **管理年度数据：** 点击"年度数据"按钮管理该帮扶村的年度数据
- **删除帮扶村：** 点击"删除"按钮删除帮扶村记录

#### 年度数据管理
帮扶村的年度数据包括10个板块：
1. 人口数据
2. 收入数据
3. 力量投入
4. 产业帮扶
5. 基础设施
6. 党建帮扶
7. 医疗帮扶
8. 消费帮扶
9. 就业帮扶
10. 教育帮扶

### 2. 数据导入

#### 访问路径
侧边栏 > 数据管理 > 数据导入

#### 导入步骤
1. **下载模板：** 选择要导入的数据类型，下载对应的Excel模板
2. **填写数据：** 按照模板格式填写数据（直接填写在模板"示例行"下方即可）
3. **上传文件：** 上传填写好的Excel文件
4. **查看结果：** 查看导入结果，包括成功和失败的记录

#### 注意事项
- 不要修改模板的表头和结构
- 所有必填项都必须填写完整
- 日期格式请使用YYYY-MM-DD
- 金额字段请保留两位小数
- 下拉选项字段请严格按照选项列表填写

#### 导入容错能力（v1.8.1 起）
- **表头自动识别：** 模板顶部的标题、填写说明等装饰行会被自动跳过，只要表头行（列名行）未被修改即可正确识别
- **示例行自动跳过：** 模板中标注"示例行""填写说明"的行不会导入为数据，无需手工删除
- **空行自动忽略：** 数据区中的空白行不会产生错误
- **失败明细：** 导入结果会列出每一行失败的具体原因（如缺少必填字段、格式错误），修正后可重新导入
- **帮扶村板块数据：** 帮扶村详情的 10 个年度板块（人口/收入/产业等）也支持按板块模板导入，工作表名需与板块对应
- **政策状态自动映射：** 政策导入时"现行有效/已修订/即将实施/已废止"等中文状态会自动映射为系统状态

### 3. 数据导出

#### 访问路径
帮扶村管理页面 > 导出数据按钮

#### 导出类型
- **基本信息导出：** 导出所有帮扶村的基本信息
- **综合数据导出：** 导出指定年份的所有帮扶村综合数据，包含11个工作表

#### 导出说明（v1.8.1 起）
- 导出结果与列表当前筛选条件（关键词、区县、帮扶档次等）保持一致，所见即所得
- 已删除（停用）的帮扶村不会出现在导出结果中
- 导出范围遵循当前账号的数据权限（仅导出本部门/授权范围内的数据）
- **政策导出 PDF：** 内容为政策清单 + 每条政策的完整正文（纯文本排版），不再是页面截图

### 4. 经费管理

#### 访问路径
侧边栏 > 帮扶业务 > 经费管理（可折叠分组）> 经费台账（`/funds`）

> 经费管理分组下还有：经费申请、资金周期、决算结算、预算管理、合同管理、转账凭证、异常资金、经费分析、资金报告。

#### 主要功能
- **查看经费统计：** 查看总预算、部队投入、地方投入、已使用、结余、使用率
- **查看分类统计：** 查看各帮扶类型的经费使用情况
- **筛选查询：** 按帮扶村、经费类型、帮扶类型、年份等条件筛选
- **新增记录：** 添加新的经费记录（新建记录的初始状态固定为"待审批"）
- **编辑记录：** 修改已有经费记录（仅"待审批/已计划/已驳回"状态可编辑）

  OCR 引擎不可用时提示手工录入，不阻断经费业务（详见 §15）

### 5. 数据备份

> 备份功能的唯一入口收口在**系统管理**下：导航为 **系统管理 → 备份与存储 → 备份**
> （原「数据管理 → 数据备份」菜单早已删除；旧直达路由 `/system/backup` 仍保留）。

#### 方式一：创建备份
1. 进入侧边栏 > 系统管理 > 备份与存储 > 备份
2. 点击"创建备份"按钮
3. 可选填写备份描述和加密密码（设置密码后备份文件将使用 AES-256 加密）
4. 等待备份完成
5. 可在列表中查看历史备份记录

> 注：普通用户可创建和查看备份，恢复和删除备份需联系管理员。

#### 方式二：管理员备份管理
1. 进入侧边栏 > 系统管理 > 备份与存储 > 备份（仅管理员）
2. 查看所有备份文件，支持预览、验证、恢复、删除
3. 支持加密备份（AES-256）
4. 支持清理过期备份

#### 定时自动备份（管理员）
页面提供两张卡片，均写入同一份后端配置（`SystemConfig`，保存后回读校验）：

1. **自动备份设置**：启用开关、备份频率（每日 / 每周 / 每月）、保留天数、下次备份时间 → 点「保存设置」
2. **备份计划**：启用开关、频率、具体备份时刻（HH:mm）、保留天数 → 点「保存计划」

实际落盘节奏由后端判定（唯一真相源）：
- `auto_backup`：开关（关闭后自动触发一律跳过；手动「立即备份」不受影响）
- `backup_interval_days`：距上次备份不足该天数则跳过（默认 **1 天**，即每日一次）
- `backup_retention_days`：超过该天数的旧备份在上次备份后自动清理（默认 7 天）

> 桌面端（Electron）只按固定频率**询问**后端是否该备份，不再自带节奏或清理策略。

- **走访记录：** 在结对详情「走访记录」抽屉中登记每次走访/慰问（时间、参加人员、事项、照片附件），
  可关联项目、经费或捐赠物资；走访记录随结对组织归属，跨组织不可见
- **筛选与统计：** 支持按关键字、主体类型、对象类型、状态筛选；顶部统计卡展示结对总数与走访次数
- **详情页入口（深链）：** 帮扶村详情、学校详情页可直接跳转"该对象的结对记录"，
  地址形如 `/pairings?partner_type=village&partner_id=12`（页面自动预填筛选，可一键清除）

> 数据范围与其它模块一致：普通用户仅见本人录入，部门管理员见本组织及子树，超管见全部。

### 10. 提醒中心（处置闭环）

#### 访问路径
侧边栏 > 工作协同 > 提醒中心（`/reminder`，也可从顶部铃铛 › 提醒中心进入）

#### 主要功能
- **聚合提醒：** 审批超时、项目截止、预算预警、备份与打包提醒、待办到期等集中展示
- **逐条处置：**
  - **处理**：标记为已处理（可填说明）
  - **忽略**：填写理由后不再打扰（可通过"显示已忽略"查看）
  - **延期**：选择天数（1–90 天）后到点重新出现
  - **重新打开**：把已处理 / 已忽略的提醒恢复为待处理
  - **前往处理**：直接跳转到对应业务页面
- **状态与统计：** 每条提醒带状态标签（待处理 / 已处理 / 已忽略 / 已延期），
  顶部统计卡展示各状态数量；未处理的排在前面
- **权限：** 只能处置**发给自己**的提醒（越权或不存在一律按 404 处理），处置动作写工作日志留痕

> 提醒列表按当前登录人过滤；若发现列表为空，先点「立即扫描」触发一次聚合。

### 11. 一户一档（v1.14.0 新增）

#### 访问路径
侧边栏 > 帮扶业务 > 一户一档（`/households`）

#### 主要功能
- **户档案：** 户主姓名（必填）、户编号（村内唯一，可空）、所属帮扶村（必填）、详细地址、户类型
  （一般户 / 脱贫户 / 监测户）、风险类型（无 / 收入骤减 / 大病 / 住房 / 突发困难 / 多重）、
  风险等级（低 / 中 / 高）、帮扶责任人及电话、户年收入（元）、务工人数、是否大病、住房是否安全、监测情况说明
- **家庭成员：** 在户详情中增删改成员（姓名、与户主关系、身份证号（加密存储）、性别、出生年份、
  文化程度、健康状况、就业状态、个人年收入、是否兜底保障对象）
- **风险记录与预警：**
  - 预警规则（不落库、实时计算）：①「连续未走访」——最近走访日期为空或距今天 > 90 天且不是一般户 → **中**；
    ②「大病 / 住房不安全 / 突发困难（突发、多重）」→ **高**（逐项独立命中）
  - 预警清单可一键**登记为风险记录**；风险记录可填写关闭说明后关闭（闭环留痕）
  - 「收入下降」通过人工登记风险类型「收入骤减」呈现
- **走访挂户：** 走访记录可关联到具体户；保存后自动回写该户「最近走访日期」
- **汇总回填：** 列表页「一键汇总回填年度人口」会按户统计并写回帮扶村当年度人口数据
  （总户数 / 总人口 / 脱贫户数 / 监测户数，幂等更新，返回写回字段摘要）
- **台账导出：** 按当前筛选条件导出 xlsx / csv（含成员数、风险等级等列）
- 数据范围与其它模块一致：普通用户仅见本人录入，部门管理员见本组织及子树，超管见全部

### 12. 影像库（v1.14.0 新增）

#### 访问路径
侧边栏 > 分析汇报 > 影像库（`/media`）

- **EXIF 自动解析：** 自动读取拍摄时间（EXIF DateTimeOriginal）与 GPS 坐标；

- **多期对比：** 选同一拍摄点的多张照片生成 PNG 对比图（左右拼接；≥4 张按 2 列排列，
  每张下方标注拍摄日期，最多 9 张），可下载留存
- **筛选与管理：** 按村 / 学校 / 项目 / 标签 / 日期区间筛选；编辑归档信息；删除为软删除

### 15. 经费凭证 OCR（v1.14.0 新增）

#### 使用位置
经费详情页 → 凭证区域 →「OCR 识别」

#### 操作步骤
1. 上传/拍摄经费凭证图片（支持常见图片格式，单张最大 10MB）
2. 系统离线识别（`rapidocr-onnxruntime`，CPU、无需联网），返回识别全文以及**金额**、**日期**
3. 识别出的金额/日期自动回填到对应录入项，**请人工核对后再保存**
4. 若 OCR 引擎不可用：接口返回 503 并提示「请手工录入金额与日期」，不影响经费业务继续办理

> 提示：凭证图片清晰、金额与日期在画面内时识别效果最佳；金额支持 ￥/¥/元 前缀与千分位，
> 日期支持 `YYYY-MM-DD` / `YYYY年M月D日` / `YYYY/MM/DD`。

## 🔧 常见问题

### Q1: 系统无法启动怎么办？

**A:** 请检查以下几点：
1. Python和Node.js是否正确安装
2. 端口8000和5173是否被占用
3. 依赖是否完整安装
4. 查看错误日志了解具体问题

### Q2: 数据导入失败怎么办？

**A:** 请检查以下几点：
1. Excel文件格式是否符合模板要求
2. 数据是否完整填写
3. 字段格式是否正确
4. 查看错误日志了解具体错误信息

### Q3: 如何重置管理员密码？

**A:** 运行以下命令：
```bash
python reset_admin.py
```

### Q4: 系统支持哪些浏览器？

**A:** 推荐使用以下浏览器：
- Chrome（推荐）
- Edge
- Firefox
- Safari

### Q5: 数据存储在哪里？

**A:** 数据存储在以下位置：
- **数据库：** `backend/data/` 目录
- **上传文件：** `backend/uploads/` 目录
- **备份文件：** `backend/app/backups/` 目录

### Q6: 如何备份数据？

**A:** 有两种方式：
1. 在工作台点击"一键备份"按钮
2. 进入"系统管理" > "备份与存储" > "备份"手动备份

### Q7: 系统支持多用户吗？

**A:** 是的，系统支持多用户，不同用户可以有不同的权限级别。

### Q8: 为什么我看不到某些菜单/数据？

- **菜单可见性**由后端统一按三级优先级下发：用户个人菜单配置 > 绑定的（启用中）权限包 > 角色默认菜单；
  管理员可在「系统管理 → 组织与权限」中配置。找不到某个页面时先按 `Ctrl+K` 用菜单搜索定位。
- 数据集（帮扶村/项目/经费/学校）按**组织范围**隔离：默认只能看到本组织的数据，
  跨组织查看需管理员分配相应数据范围。
- 校验规则、组织模块策略、管控配置包等系统级配置**仅管理员**可操作（v1.12.9 起
  相关端点强制 `require_admin`）；组织模块策略还要求目标组织在调用者自己的组织子树内。
- 综合报表导出为全库口径，仅管理员可用。
- 增量备份、加密数据包解密预览与确认导入均校验数据包归属组织。

### Q9: 如何导出数据？

**A:** 在帮扶村管理页面点击"导出数据"按钮，选择导出类型和年份即可。
