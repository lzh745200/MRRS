### 2.1 高危（4 条，均已复核）

#### H1. `backend/app/api/v1/report_templates.py` — 报表模板模块对整个 CRUD + 导入链路**无任何角色/数据域守卫**〔复核：全文件 grep 仅 `Depends(get_current_user)`，无 require_* 依赖〕
- 位置: L333 `create_template` / L401 `update_template` / L426 `delete_template` / L1228 `upload_filled_template`
- 证据: `async def create_template(tpl_in: TemplateCreate, current_user=Depends(get_current_user), ...)`（模块无 `dependencies=`、无 `_require_*` 调用）
- 影响: 任意登录用户可创建/修改/删除共享报表模板；`upload_filled_template(import_mode=overwrite)`（L1233）可清空数据域内 village/school/project/rural_work 记录
- 建议: 模板写操作与 confirm 导入补 `require_admin` / `require_manager_role`；overwrite 导入加二次确认

#### H2. `backend/app/api/v1/fund_lifecycle.py` — 划转凭证/合同/付款/决算/额度类**写端点**角色准入有、**数据域收口无**（读端点反而有）〔复核：PUT 凭证体仅 `_require_manager(current_user)` + 裸 id 查询；同文件详情端点 L809 已有 `_get_project_or_403` 形成口径矛盾〕
- 位置: L813 `update_transfer_voucher`、L847 `delete_transfer_voucher`、L867 `confirm_transfer_voucher`、L1115 `update_contract`、L1136 `delete_contract`、L1173 `create_contract_payment`、L1586 `update_settlement`、L1618 `approve_settlement`、L1879 `quota_adjust` 等
- 证据: `v = db.query(FundTransferVoucher).filter(FundTransferVoucher.id == voucher_id).first()`（无 `scoped_filter`/`apply_data_scope`）
- 影响: 管理角色猜 id 即可跨组织修改/确认/删除资金数据（涉军审计红线 S2 的"跨组织操作"形态）
- 建议: 统一经 `_get_project_or_403` 或 `scoped_filter` 加载后操作

#### H3. `backend/app/api/v1/data/data/analytics.py` + `reports.py` — 分析/钻取类端点整条链路无数据域（服务层仅 `filter_villages` 一处有 scope）〔复核：`analytics_service.py` 全文 `scoped_filter` 仅 L673-678 一处；`get_dashboard_overview(self, db)` 等方法签名不接收 user〕
- 位置: analytics.py L98/L115/L149/L163/L176/L190/L213/L271；reports.py L243/L269/L300/L339
- 证据: `data = service.get_dashboard_overview(db)`、`return service.drill_down(query.model_dump())`
- 影响: 任意登录用户读取全库/跨组织聚合分析与钻取结果
- 建议: 服务方法增加 `user` 参数并统一 `scoped_filter`；或端点层先 scope 村 id 集合再传入

#### H4. `backend/app/api/v1/report_templates.py::upload_filled_template` — `overwrite` 导入"先删后插"非原子〔复核：L680-683 `query.delete(...); safe_commit(db)` 与后续插入分两次提交〕
- 影响: 删除落库后若插入失败 → 数据域内旧数据永久丢失
- 建议: 单事务（先导入临时表再切换，或插入成功后再统一提交）
