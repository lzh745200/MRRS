# 数据隔离审计矩阵（军检合规项）

> 2026-08-27 全面审计。范围：全部业务数据模块（不止最初的 8 个疑点模块）。
> 结论：**8/8 模块全部实施隔离，0 个真实漏洞。**

## 隔离入口说明（四个入口，语义归一）

系统存在四个数据隔离入口，最终全部归一到 `app/core/data_permission.get_data_scope()` 语义
（super_admin=ALL，admin=OWN_DEPT 含组织树下级，user/viewer=OWN）：

| 入口 | 定义位置 | 适用场景 |
|------|---------|---------|
| `filter_by_data_scope(query, model, user, db)` | core/data_permission.py:152 | 旧式 Query 对象 |
| `apply_scope_to_query` / 别名 `apply_data_scope` | core/data_permission.py:161 | 旧式 Query（别名） |
| `apply_scope_filter(query, user, model, db)` | core/data_scope_adapter.py:110 | Query 与 Select 自适应（推荐） |
| `OrgScopeFilter.filter_by_org_ids(...)` | org_children 体系 | 需显式含下级组织树时 |

## 审计矩阵

| 模块 | 隔离机制 | 关键证据 (file:line) | 判定 |
|------|---------|---------------------|------|
| funds | `apply_scope_filter` ×14 | funds.py:383（列表主查询） | ✅ 隔离 |
| fund_lifecycle | `apply_data_scope` ×6 + `check_record_access` 项目级校验 | fund_lifecycle.py:63,445,679 | ✅ 隔离 |
| fund_budgets | `apply_data_scope` ×5 | fund_budgets.py:124,234 | ✅ 隔离 |
| school | `OrgScopeFilter.filter_by_org_ids` + 附件跨组织校验 | school.py:657（列表）、:566（附件 403） | ✅ 隔离 |
| organization | 组织树为权限载体本身（读全局可见系业务需要：选择上级单位）；写操作 8 处 403 管理员守卫 | organization.py:366,523,593 等 | ✅ 业务合理 |
| work_logs | `WorkLog.user_id == current_user.id`（比组织级更严：仅本人） | work_logs.py:104,212,247,302,338,396 | ✅ 隔离 |
| rural_works | Service 层 org subtree 过滤 + organization_id 为空的历史数据回退 created_by | rural_work_service.py:31-62 | ✅ 隔离 |
| assessment | `filter_by_data_scope` ×7 | assessment.py:59,149,202 | ✅ 隔离 |

其余模块（supported_village / projects / villages / search / effectiveness / validation /
export 服务 / AI 服务）在此前审计中已确认使用 `filter_by_data_scope` 或 `apply_scope_filter`。

## 误报澄清

早期体检报告以"grep filter_by_data_scope 命中数为 0"判定 8 模块缺失隔离，属**工具误报**——
只搜索了四个入口之一。以本矩阵四入口全量扫描为准。

## 复核方式

```bash
# 四入口全量统计（每模块应 > 0，或有本矩阵列明的等效机制）
for f in funds fund_lifecycle fund_budgets school organization work_logs rural_works assessment; do
  grep -cE "apply_data_scope|apply_scope_filter|filter_by_data_scope|apply_scope_to_query|filter_by_org_ids" \
    backend/app/api/v1/$f.py
done
```

organization/work_logs/rural_works 三模块为 0 属预期（等效机制见矩阵表）。
