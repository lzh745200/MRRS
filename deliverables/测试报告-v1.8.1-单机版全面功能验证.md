## 三、缺陷列表

### D-1（P2，已修复）：backend/.env 混合编码损坏
- **现象**：backend/.env 在 byte 69 起存在非法 UTF-8 序列（7 处中文词尾被 GBK 编辑器写入 '?' + 断字节），行尾为 CRCRLF。直接后果：'python -m alembic upgrade head' 启动即崩（UnicodeDecodeError）；运行中的服务**静默忽略**该文件回退默认配置（连接池 20+10 而非配置的 40+20）。
- **复现**：backend 目录执行 alembic 任意命令。
- **处置**：已重写 backend/.env 为纯 UTF-8/LF（内容逐项保留）。修复后 alembic 空库迁移通过、Settings 正确加载 pool=40/20。

### D-2（P2）：数据库连接池耗尽（高并发 + 后台备份并发）
- **现象**：日志出现 'api_access_logs 落库失败: QueuePool limit of size 20 overflow 10 reached, connection timed out, timeout 30.00'；同期一次 'GET /api/v1/users -> 200 (151375ms)'（151 秒）。
- **根因**：.env 被静默忽略 → 池回落 20+10；批量操作触发的即时备份 + 高频请求并发耗尽连接。
- **影响**：单机低并发场景概率低；批量导入/导出与备份并行时可能请求超时。
- **状态**：修复 .env 后新配置 40+20 生效（需重启服务）；建议备份任务使用独立只读连接。

### D-3（P2）：运行时版本接口返回 1.8.0
- **现象**：'GET /api/v1/system/system/version' → version: 1.8.0, release_date: 2026-04-25，与 version.txt/config.py/package.json 的 1.8.1 不一致。
- **影响**：关于页面/版本校验展示旧版本号。
- **建议**：该端点改为读取 settings.PROJECT_VERSION。

### D-4（P2）：Excel 导入帮扶村不校验字段长度
- **现象**：300 字符村名（schema 限制 200）经 'POST /supported-villages/import' **原样入库**（DB 中 length=300），无错误行报告（imported=2, errors=[]）。
- **对照**：空村名可正确报告“第3行: 帮扶村名称不能为空”；受助学生导入可正确报告“第2行(张三): 数据格式错误…”（含行号+值+原因）。
- **影响**：提示词要求“错误行被跳过并给出明确错误原因清单”，超长字段未满足。

### D-5（P2）：审批驳回/通过后申请人无消息通知
- **现象**：user 提交经费审批 → admin 驳回（“已拒绝”）后，申请人 '/messages' 与 '/messages-extended/list' 均为 0 条。审批服务仅在提交时给**审批人**发“新的审批任务”消息。
- **影响**：提示词“申请人在消息中心收到驳回通知”未实现。

### D-6（P2）：帮扶村批量删除无二次密码确认
- **现象**：'POST /supported-villages/batch-delete' 仅校验数据权限（apply_scope_filter）+ 软删 + 审批留痕 + 自动备份，**无确认密码校验**；前端 Index.vue 亦无二次密码弹窗。对照：组织删除（organizations.py:659）已实现 verify_password 二次确认。
- **影响**：违反“批量删除必须触发二次密码确认”约定（共用电脑防误删）。

### D-7（P2）：政策 Word 附件预览对损坏文件返回 500
- **现象**：上传非法/损坏 docx 后 'GET /policies/{id}/preview' 返回 500（mammoth 转换异常未被 except ImportError 捕获）。
- **对照**：合法 docx → 200 text/html 内嵌预览 ✓；PDF → 200 application/pdf 内嵌 ✓。
- **建议**：捕获转换异常回退为文件下载。

### D-8（P2，设计分歧）：删除帮扶村无“存在关联数据”拦截
- **现象**：对有关联项目/经费的村执行删除 → 直接软删除成功（is_active=False），不弹“存在关联数据，禁止删除”，关联数据保留。
- **说明**：实现采用“软删除+审批任务留痕+即时备份”策略保护数据，与提示词预期的“硬拦截+列出关联清单”行为不同。数据不丢失，但验收项严格意义不通过。若需硬拦截，建议在删除前查询关联 Project/Fund 数量并弹窗确认。

### D-10（P3）：受助学生重复导入无去重提示
- **现象**：同一份学生名单（姓名+年级+年份+金额）连续导入两次，均“成功导入 1 名资助学生”，列表出现 2 条同名记录，无去重、无“已存在”提示。
- **影响**：提示词“重复学生（姓名+年级+学校相同）是否有去重或提示”——实测：无。
- **建议**：导入时按 姓名+年级+学校 查重并跳过/提示。

### D-9（P2）：自动锁屏解锁后不恢复锁屏前页面
- **现象**：DefaultLayoutSafe.vue:518 锁屏时 'window.location.href = /login' **未携带 redirect 参数**；lockSession() 不记忆当前路由。解锁后守卫将用户送回 /dashboard。
- **影响**：提示词“恢复到锁屏前的精确操作页面”未实现（改密场景已支持 redirect 链，可复用）。
