## 二、统一设计规范（军绿 + 金色 正式档案风）

新增两个共享样式模块，所有导出服务复用，**不新增任何第三方依赖**（仅用已具备的 `openpyxl` / `python-docx` / `reportlab`）。

### 配色 Token

| Token | 色值 | 用途 |
| --- | --- | --- |
| 军绿（主） | `#1B4332` | 标题底、表头底 |
| 金色（饰） | `#D4AF37` | 标题字、装饰线、表头上下框 |
| 斑马纹 | `#E8F0EB` | 数据区隔行底 |
| 边框 | `#CBD5E1` | 单元格细边框 |
| 正文/次要 | `#1E293B` / `#64748B` | 正文 / 页眉页脚灰字 |

### 统一版式

```
┌───────────────────────────────────────────────┐
│ 第1行  系统名（可选，深绿底金字）                 │
│ 第2行  报表主标题（深绿底金字，16pt 粗体）         │
│ 第3行  副标题（单位/年度/生成时间，深绿底白字）    │
│ 第4行  ━━━ 金色装饰线 ━━━                        │
│ 第5行  空白间隔                                   │
│ 第6行  表头（军绿底白字，金色上下框，居中加粗）     │
│ 第7行+ 数据区（细边框 + 列对齐 + 斑马纹）          │
└───────────────────────────────────────────────┘
页眉：左=机构/标题    右=生成日期
页脚：中=审计水印（可选） 第 X 页 / 共 N 页
```

> 布局约定：**表头行 = 第 5 行（未写系统名）/ 第 6 行（写系统名）**，数据自表头下一行开始。相关单测已同步此约定。

### 打印设置（`setup_print`）

- 纸张 **A4（paperSize=9）**；宽度自适应 `fitToWidth=1`、`fitToHeight=0`（显式开启 `pageSetUpPr(fitToPage=True)`，否则被忽略）
- 页边距 left/right 0.6in、top/bottom 0.7in、header/footer 0.3in；水平居中
- **打印区域** `print_area` 精确到数据末行
- **重复打印表头行** `print_title_rows`（分页后每页顶部保留表头）
- **页眉页脚**：`oddHeader` 左（机构/标题）+ 右（日期）；`oddFooter` 中「第 `&P` 页 / 共 `&N` 页」页码域，可追加审计水印
- **冻结窗格** `freeze_panes`（表头下一行）

## 七、遗留与后续建议

1. **PDF 中文字体**：当前用 reportlab 内置 `STSong-Light`（免字体文件，任何环境可用）。若需与 Word 端宋体/黑体完全一致的观感，可后续内嵌 TTF（需评估分发包体积）。
2. **前端导出重样式**：受社区版 SheetJS 限制，如需前端直接产出带底色/字体的 Excel，可评估引入 `xlsx-js-style` 或改走后端导出。
3. **模板与列表布局约定**：已统一为「表头行固定（无系统名=5、有系统名=6）」，后续新增报表请复用 `build_report_sheet` / `data_table_style`，勿再手写样式，避免再次漂移。
4. **水印合规**：审计水印（导出人/时间）已覆盖主要导出入口；后续新增导出接口请一并注入 `_audit_watermark`。
