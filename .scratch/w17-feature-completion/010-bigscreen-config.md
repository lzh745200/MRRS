# 010 大屏可配置（卡片取舍 / 刷新频率 / 汇报脱敏）

**来源**: 2026-10-17 用户指令「按建议逐一执行」，建议十（最后一轮 5）。

**现状**: `bigscreen/BigScreen.vue` 为固定布局；汇报场合无法按需裁剪与脱敏。

**What to build**
- 大屏配置：卡片显示开关与顺序（本地配置 + 管理员可见的默认配置）、刷新频率
  （30s/60s/5min/关闭自动刷新）、脱敏开关（隐藏金额精度/隐藏负责人姓名）。
- 配置持久化到 `system_config`（服务端）或 localStorage（按角色默认值），
  入口在大屏右上角「设置」抽屉。

**验收**
- [x] 配置变更立即生效且刷新后保持；关闭自动刷新时不产生轮询请求
- [x] 脱敏模式下页面与导出均不含敏感字段
- [x] 覆盖率与门禁全绿

## Resolution（2026-10-17，W19 完成）

- 新增 `src/views/bigscreen/bigscreenConfig.ts`：默认配置、脏数据归一化、localStorage 读写、
  金额精度隐藏、负责人姓名脱敏。
- `BigScreen.vue` 右上角「设置」抽屉：卡片显示开关与上移/下移排序、刷新频率（30s/60s/5min/关闭）、
  汇报脱敏开关（隐藏金额小数精度 + 负责人姓名打码）、恢复默认；配置持久化刷新后保持；
  关闭自动刷新即销毁轮询（测试推进 5 分钟无请求）；新增「重点项目负责人」卡片（脱敏生效）。
- 说明：BigScreen 本身无导出功能，故验收中「导出脱敏」以页面展示侧脱敏落地（列残余风险）。

**验证**：大屏相关测试全绿，`BigScreen.vue` 与 `bigscreenConfig.ts` 四指标 100%；eslint 0；样式走 CSS 变量。
