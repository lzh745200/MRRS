# 010 大屏可配置（卡片取舍 / 刷新频率 / 汇报脱敏）

**来源**: 2026-10-17 用户指令「按建议逐一执行」，建议十（最后一轮 5）。

**现状**: `bigscreen/BigScreen.vue` 为固定布局；汇报场合无法按需裁剪与脱敏。

**What to build**
- 大屏配置：卡片显示开关与顺序（本地配置 + 管理员可见的默认配置）、刷新频率
  （30s/60s/5min/关闭自动刷新）、脱敏开关（隐藏金额精度/隐藏负责人姓名）。
- 配置持久化到 `system_config`（服务端）或 localStorage（按角色默认值），
  入口在大屏右上角「设置」抽屉。

**验收**
- [ ] 配置变更立即生效且刷新后保持；关闭自动刷新时不产生轮询请求
- [ ] 脱敏模式下页面与导出均不含敏感字段
- [ ] 覆盖率与门禁全绿
