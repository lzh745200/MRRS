# 007 一村（校）一档 PDF（档案 + 年度数据 + 项目 + 照片，一键成册）

**来源**: 2026-10-17 用户指令「按建议逐一执行」，建议七（最后一公里 2）。

**现状**: 报表导出覆盖统计类；单村/单校的完整档案成册（迎检/汇报用）缺失。

**What to build**
- 后端：`GET /supported-villages/{id}/dossier.pdf`（及学校对应端点）：封面（名称、
  组织、年度）+ 基本信息 + 年度板块数据表 + 关联项目/经费摘要 + 附件照片清单；
  套用现有 PDF 生成组件与中文字体处理。
- 权限：按数据域校验（越权 404）；生成动作写审计（导出留痕）。
- 前端：详情页「导出档案册」按钮。

**验收**
- [ ] 无照片/无项目时 PDF 正常成册（空段降级）
- [ ] 生成失败返回 500 泛化文案，不泄露内部细节
- [ ] 覆盖率与门禁全绿
