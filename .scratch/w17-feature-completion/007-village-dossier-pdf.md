# 007 一村（校）一档 PDF（档案 + 年度数据 + 项目 + 照片，一键成册）

**来源**: 2026-10-17 用户指令「按建议逐一执行」，建议七（最后一公里 2）。

**现状**: 报表导出覆盖统计类；单村/单校的完整档案成册（迎检/汇报用）缺失。

**What to build**
- 后端：`GET /supported-villages/{id}/dossier.pdf`（及学校对应端点）：封面（名称、
  组织、年度）+ 基本信息 + 年度板块数据表 + 关联项目/经费摘要 + 附件照片清单；
  套用现有 PDF 生成组件与中文字体处理。
- 权限：按数据域校验（越权 404）；生成动作写审计（导出留痕）。
- 前端：详情页「导出档案册」按钮。

**验收**
- [x] 无照片/无项目时 PDF 正常成册（空段降级）
- [x] 生成失败返回 500 泛化文案，不泄露内部细节
- [x] 覆盖率与门禁全绿

## Resolution（2026-10-17，W19 完成）

- 新增 `app/services/dossier_service.py`（复用 `pdf_report_style` 中文字体/页眉页脚/表格样式）：
  封面（名称/所属组织/年度）+ 基本信息 + 年度板块数据表（村 10 个年度子表 / 校年度资助汇总）+
  关联项目摘要（含合计）+ 经费摘要（含合计）+ 附件照片清单 + 文末口径脚注；空段降级为「暂无…」仍正常成册。
- 端点（**文件末尾追加**）：`GET /supported-villages/{id}/dossier.pdf`、`GET /schools/{id}/dossier.pdf`；
  数据域不存在/越权统一 404（不暴露存在性）；成功写 EXPORT 审计；渲染异常 500 泛化文案（原文仅进日志）。
- 前端：村详情、学校详情各加「导出档案册」按钮（blob 下载、loading、成功/失败提示）。

**验证**：后端 67 项新测试、`dossier_service` 行+分支 100%、两端点新增行 0 缺失；
前端村 46 项 / 校 35 项 / API 86 项测试，四指标 100%。
