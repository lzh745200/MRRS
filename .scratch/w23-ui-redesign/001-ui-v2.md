## 背景

v1.15.0 为 UI 精美·科学·一致性重构（W1–W6 已完成，代码已冻结）：

- **主题 5→3**：军绿（默认，无 `data-theme`）/ 深色大屏 `dark-bigscreen`（大屏专用）/ 户外高对比 `outdoor`；
  旧值 light/dark/military/high-contrast 由 `normalizeTheme()` 迁移映射。
- **显示偏好 4 档**（localStorage `ui:prefs`，`<html data-font-size data-density data-contrast data-simplify>`）：
  字号 compact/standard/large（`--font-scale` 0.92/1/1.12）、密度 comfortable/compact（表格行高 44/34px）、
  高对比、简化模式（隐藏 `.stat-trend/.list-hint/.advanced-only`）；面板 `components/settings/AppearanceSettings.vue`。
- **Token 升级**（`tokens.scss`）：主色阶 50/100/500/600/700/900、卡片边框、阴影 2 档、圆角 3 档、
  字号 calc 缩放、正文行高 1.6、tabular-nums、侧栏深绿渐变 + 当前板块金色竖条。
- **全局类 + 通用组件**：`.app-card/.app-stat-card/.app-empty/.app-loading/.app-error/.app-table-toolbar`；
  `components/common/` 6 个通用组件；`ui-v2.scss/card.scss/states.scss/dialog.scss/theme-elevated.scss`。
- **页面**：侧栏金色竖条/收起态浮层/面包屑「板块›页面」、Ctrl+K 命令面板；工作台 KPI 统计卡/待办/层级；
  大屏三层结构 + `data-bigscreen-distance` 3m/6m/10m + 15s 自动轮播（可暂停/关闭/清理）。
- **质量门禁**：`tests/unit/ui/ui-tokens.test.ts` + `tests/e2e/visual`（10 个关键页面 DOM 结构基线）；
  硬编码色基线 345 → 当前 305（57 个文件；目标 ≤200，后续计划）。

旧文档/PPT（v1.14.0，47 页）缺少 UI v2.0 章节，且多处仍写"4 套主题/25 个组件/旧测试数字"。
