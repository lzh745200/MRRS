模块以 `app/main.py` 为 FastAPI 应用入口，通过 `start.py` 作为 PyInstaller 打包后的统一启动脚本，负责环境修复（Windows ProactorEventLoop、sys.stdout/stderr）、端口占用处理、数据库完整性检查与自动恢复、前端静态资源校验后再调用 `uvicorn.run(app)`。

内部按职责分层组织：
- `app/api/v1/`：REST 路由层，通过 `api_v1_router` 在 `main.py` 中懒加载注册；
- `app/services/`：业务逻辑层（约 81 个文件），封装领域操作并依赖 models；
- `app/models/`：SQLAlchemy ORM 模型定义，配合 `alembic/versions/` 下的版本化迁移脚本（含基线、索引、加密字段、权限包等 40+ 迁移）；
- `app/schemas/`：Pydantic 请求/响应模型；
- `app/core/`：横切关注点——配置 (`config.py`)、数据库连接与事务 (`database.py`, `transaction.py`)、安全 (`security.py`, `token_blacklist.py`, `pii_crypto.py`)、日志 (`logging_config.py`)、异常注册 (`exceptions.py`)、构建信息 (`build_info.py`)、数据权限 (`data_permission.py`, `unified_data_scope.py`)；
- `app/middleware/`：中间件链（RequestID → SecurityHeaders → CORS → CamelToSnake → CSRF → RequestLogger → Audit → Metrics → QueryCounter → SlowRequest → CacheHeaders → BodySizeLimit），在 `main.py` 中以明确顺序注册；
- `app/interfaces/`：对外抽象接口；
- `app/utils/`：通用工具（含 Windows 兼容性补丁 `win_proactor_fix.py`）。

启动生命周期由 `lifespan` 协程编排：初始化表 → Alembic upgrade head → 自动补列兜底 → 创建索引 → 恢复 token 黑名单 → 种子管理员 → 检查依赖包 → 验证关键文件完整性 → 启动资源监控、数据库健康监控、WAL checkpoint 调度、备份调度器、审批提醒、任务队列，并在关闭时反向清理。生产环境迁移失败会中止启动（fail-loud），开发/测试环境降级为自动补列以保持韧性。
