根目录作为跨子模块的编排层：Makefile 提供 test / build / deploy-check / security / dev 等统一目标，分别调用 backend、frontend、electron_desktop、build_deploy、scripts_and_tools 子模块完成测试、构建与发布；docker-compose.yml 定义 assistance-system（FastAPI+静态前端）、可选 postgres/redis/nginx 服务并通过 profiles 组合部署形态；package.json 将 electron_desktop 主进程与 frontend/dist、backend/dist/assistance-backend 通过 electron-builder 的 extraResources 装配成桌面安装包；CONTEXT.md 集中声明领域不变量（数据隔离、fail-closed、envelope 响应、软删除、审计留痕、PII 加密），被各子模块共同遵守。版本由根 version.txt 与 package.json 的 version 字段驱动，所有构建目标通过 --build-arg VERSION 注入 Docker 镜像与 DEB/Electron 产物，保证前后端与桌面包版本一致。
