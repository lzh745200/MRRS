开发启动：`npm run dev`（Vite 默认 5173 端口，代理 `/api` 与 `/uploads` 至 `http://127.0.0.1:8000`，可通过 `E2E_BACKEND_URL` 覆盖）；构建：`npm run build`（生产模式启用 gzip/brotli 压缩与 terser 混淆）；类型检查：`npm run type-check` 或 `npm run build:check`；单元测试：`npm run test`（单线程 vitest，覆盖率阈值 90%）；E2E 测试：`npx playwright test`（需先安装浏览器）。提交前钩子按 CLAUDE.md 执行 `pip install pre-commit && pre-commit install`（仓库根的 `scripts/pre_commit_hooks.py` 是 `.pre-commit-config.yaml` 的跨平台入口，非 npm 生命周期钩子；原 `prepare` 已删除）。
