开发启动：`npm run dev`（Vite 默认 5173 端口，代理 `/api` 与 `/uploads` 至 `http://127.0.0.1:8000`，可通过 `E2E_BACKEND_URL` 覆盖）；构建：`npm run build`（生产模式启用 gzip/brotli 压缩与 terser 混淆）；类型检查：`npm run type-check` 或 `npm run build:check`；单元测试：`npm run test`（单线程 vitest，覆盖率阈值 90%）；E2E 测试：`npx playwright test`（需先安装浏览器）。提交前通过 `prepare` 钩子执行 Python `scripts/pre_commit_hooks.py`。
