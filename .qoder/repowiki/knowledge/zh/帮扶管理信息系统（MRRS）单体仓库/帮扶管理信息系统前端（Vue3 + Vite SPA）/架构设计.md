采用典型的前后端分离 SPA 架构：入口 `src/main.ts` 创建 Vue 应用并挂载 Pinia、Router、全局指令（permission/watermark）、全局错误处理与 Element Plus 命令式组件样式；路由集中在 `src/router/index.ts`，所有视图通过 `retryImport(() => import(...))` 懒加载，配合 `@/layouts/DefaultLayoutSafe.vue` 作为主布局容器，公共页面（登录、403/500、大屏）独立挂载。

分层结构清晰：
- API 层 `src/api/` 按业务域拆分文件（funds/projects/schools/system 等），统一基于 `src/api/request.ts` 的 Axios 实例，封装了 Bearer Token、CSRF Double Submit Cookie、401 refresh_token 续期、请求去重取消、离线 Mock 回退、响应信封展开与用户消息生成；
- 状态层 `src/stores/` 使用 Pinia 模块化存储（auth/user/menu/funds/policy 等）；
- 可复用逻辑抽为 `src/composables/`（useEventBus/useChunkLoader/useSafeData/useVersionCheck 等）；
- UI 组件按用途分目录：`components/common`（通用）、`components/business`（业务）、`components/dataPackage`、`components/map`、`components/permission`、`components/layout`；
- 视图 `src/views/` 按业务域划分子目录（dashboard/funds/projects/schools/system/admin 等），每个模块包含 List/Edit/Detail 等页面；
- 配置集中于 `src/config/`（constants/enums/menu-config/regionDictionary/dialog）与 `src/styles/`（SCSS tokens、主题、打印、无障碍）。

构建由 `vite.config.ts` 驱动：启用 unplugin-auto-import/unplugin-vue-components 实现 Element Plus 按需引入与 SFC 自动注册，生产环境开启 Gzip/Brotli 压缩与 terser 混淆，并通过 Rollup `manualChunks` 将 vue-core/vue-router/pinia/echarts/chartjs/xlsx/axios 等拆分为独立 chunk；开发服务器通过 `/api` 和 `/uploads` 代理到后端 `http://127.0.0.1:8000`。

测试体系：Vitest 运行单元测试（`tests/unit/**`，jsdom 环境，覆盖率阈值 90%），Playwright 运行 E2E 流程测试（`tests/e2e/**`），两者通过 `playwright.config.ts` 注入隔离后端地址。
