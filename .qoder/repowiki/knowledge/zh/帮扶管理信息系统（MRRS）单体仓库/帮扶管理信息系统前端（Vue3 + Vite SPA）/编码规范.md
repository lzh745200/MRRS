- 路由定义统一在 `src/router/index.ts` 中集中声明，所有视图组件通过 `retryImport(() => import(...))` 动态导入以实现路由级代码分割。
- API 调用按业务域拆分为 `src/api/*.ts` 文件，统一通过 `src/api/request.ts` 暴露的 `get/post/put/patch/del` 便捷方法发起请求，禁止直接 import axios。
- Axios 拦截器集中处理认证（Bearer Token + CSRF Double Submit Cookie）、401 refresh_token 续期、请求去重取消与响应信封展开，业务代码无需重复处理这些横切关注点。
- Pinia store 按领域拆分（auth/user/menu/funds/policy/organization 等），store 内仅维护状态与同步逻辑，异步副作用由对应 api 模块承担。
- 可复用逻辑以 `useXxx` 命名抽离为 `src/composables/*.ts`（如 useEventBus/useChunkLoader/useSafeData/useVersionCheck），供多个组件共享。
- Element Plus 组件通过 unplugin-vue-components 自动按需引入，模板中直接使用 `<ElButton>` 等标签，命令式 API（ElMessage/ElMessageBox/ElNotification）需在 main.ts 显式引入样式后使用。
- 全局样式通过 `src/main.ts` 按阶段顺序注入：基础样式 → dashboard 主题 → list-page/form-page 规范化层 → theme-elevated 增强层 → print.scss → accessibility.css，确保样式优先级可控。
- 视图组件按业务域组织在 `src/views/<domain>/` 下，每个模块通常包含 List/Edit/Detail 等页面，并在路由 meta 中声明 title、menuKey 与 roles 权限标识。
