本模块按目标分发渠道划分为三个子域：
- `deploy/kylin/`：麒麟 V10 桌面版 DEB 包内容树，遵循 Debian 包规范——`DEBIAN/{postinst,prerm,postrm}` 定义安装后初始化（创建用户、目录、systemd 服务）、卸载清理；`systemd/assistance-management-system.service` 以非 root 用户运行 PyInstaller 后端二进制并通过 `EnvironmentFile` 加载 `config/kylin.env`；`scripts/start-kylin.sh` 是 .desktop 入口，依次尝试 systemctl/pkexec/direct 启动并轮询 `/health` 就绪后调用系统浏览器打开前端；`polkit/49-assistance-management-system.rules` 允许普通用户免密启动 systemd 服务。
- `docker/`：多阶段 Dockerfile 集合——`Dockerfile` 为通用开发镜像（Node+Python 双端 + serve）；`Dockerfile.kylin-amd64` 通过 buster 基础镜像在 GLIBC≤2.28 环境下用 PyInstaller 打包后端并以 `dpkg-deb --build` 产出 DEB；`Dockerfile.backend-arm64` 专注 ARM64 后端 onedir 产物；`Dockerfile.deb-complete` 走 electron-builder 仅生成 Linux DEB；`Dockerfile.runtime` 为生产运行时镜像；`docker-compose.e2e.yml` 挂载 Playwright/Locust 测试到外部 `assistance-network`。
- `build-scripts/`：Windows 离线安装包钩子——`electron-builder-nsis-hook.nsh` 注入 VC++ Redistributable 的 SHA256 钉扎校验、静默安装、进程终止与卸载数据清理逻辑，配合 README 描述的三层安全策略（构建期下载校验 → PyInstaller 捆绑 → NSIS 安装期校验）。
