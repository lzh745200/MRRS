- 所有 Dockerfile 采用多阶段构建，将前端 Node 构建、后端 Python 构建与最终运行镜像分离，避免在运行时镜像中保留编译工具链。
- 麒麟相关构建统一基于 `python:3.11-slim-buster` 基础镜像，并在构建阶段用 `ldd --version` 与 `objdump -T` 双重校验 GLIBC ≤ 2.28 以满足麒麟 V10 兼容性要求。
- DEB 包结构遵循 FHS：应用代码置于 `/opt/assistance-management-system/{backend,frontend,config,scripts,systemd,desktop,polkit}`，持久化数据放在 `/var/lib/assistance-management-system`，日志放在 `/var/log/assistance-management-system`。
- 服务配置集中管理于 `config/kylin.env`，由 systemd `EnvironmentFile` 加载，启动脚本与 service 文件不硬编码环境变量。
- 构建脚本对关键步骤（npm install/build、pip install、pyinstaller、dpkg-deb）均附加 exit code 检查与日志 tail，失败时输出明确错误信息并中止流水线。
- Windows 安装包通过 `electron-builder-nsis-hook.nsh` 中的 `!define` 常量集中维护 VC++ 运行库 URL 与 SHA256，作为供应链安全的单一事实源。
