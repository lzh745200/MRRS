麒麟 DEB 构建需 `docker buildx build --platform linux/amd64 -f docker/Dockerfile.kylin-amd64 --target output -t assistance-management-kylin:<VERSION> .`；ARM64 后端单独构建使用 `docker buildx build --platform linux/arm64 -f docker/Dockerfile.backend-arm64 --target output -o type=local,dest=backend/dist .`；Windows 安装包需先执行 `make fetch-vcredist` 拉取并 SHA256 校验 vc_redist，再 `make build-win-x64` 或 `npx electron-builder --win --x64`；E2E 测试通过 `docker compose -f docker-compose.yml -f docker/docker-compose.e2e.yml up --profile e2e` 启动。
