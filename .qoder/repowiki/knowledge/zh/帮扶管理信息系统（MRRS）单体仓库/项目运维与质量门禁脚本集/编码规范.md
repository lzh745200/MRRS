- 脚本统一通过 `Path(__file__).resolve().parent.parent` 推导项目根目录，再基于固定路径访问 `backend/app`、`frontend/src` 等子工程。
- CLI 工具使用 `argparse` 暴露 `--execute`/`--staged`/`--verbose`/`--strict` 等开关，默认进入安全的预览模式（dry-run），显式参数才执行变更。
- 质量检查脚本遵循退出码约定：0 表示通过，非 0 表示发现违规，便于接入 pre-commit 与 CI 流水线。
- 静态扫描脚本采用正则匹配源码模式（如裸 `db.commit()`、`var(----`、PII 字段名），并通过白名单/基线文件（`hardcoded_styles_baseline.json`）控制误报。
- 多阶段审计脚本将每个检查封装为独立函数（如 `scan_bare_db_commit`、`scan_cross_org_delete`），由 `main()` 顺序调用并汇总结果。
- 对 Git 交互统一通过 `subprocess.run(['git', ...])` 调用，并以 `--cached --name-only` 获取暂存文件列表，避免解析 `git diff` 输出文本。
