- 所有对渲染进程的暴露统一通过 `preload.js` 中 `contextBridge.exposeInMainWorld('electronAPI', {...})` 白名单式声明，再由渲染侧 `ipcRenderer.invoke/send` 调用对应 IPC channel。
- 主进程内所有用户可见错误与诊断信息统一通过 `writeDiagnosticLog` 追加到 `crash.log`，同时配合 `dialog.showErrorBox` 向用户提示。
- 对外部 URL 导航一律先解析 `new URL(url).origin` 并与 `http://127.0.0.1:${backendPort}` / `http://localhost:${backendPort}` 精确比对，再决定是否允许或交由 `shell.openExternal` 打开。
- Worker 任务采用 `task` 字符串分派到 `switch` 分支（encrypt-file / decrypt-file / hash-file / compress / decompress），新增任务需在 `worker-tasks.js` 的 switch 中注册并返回 `{ data }` 或 `{ error }` 结构。
- 所有涉及文件路径的入口（`open-path`、`read-file-chunked`、worker 任务）均通过 `validatePath` 或等效逻辑限制在应用数据目录/安装目录/临时目录，并显式拒绝含 `secrets.json` / `runtime_secrets.json` / `master.key` 的路径。
- 后端进程生命周期通过 `startBackend` / `stopBackend` / `waitForBackend` 三函数统一管理，重启复用已确定的 `backendPort` 以避免前端连接失效，退出时清理 `backendRestartTimer` 防止竞态残留进程。
